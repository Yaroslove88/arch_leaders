## Новая структура данных

Каждый квест теперь имеет:

```typescript
{
  description: string,        // Краткое описание (без шагов/критериев/теории)
  steps_json: Array<{         // Структурированные шаги
    order: number,
    title: string | null,
    description: string
  }>,
  criteria_json: {            // Критерии успеха
    type: string,
    items?: string[],         // Список критериев
    theory_and_examples?: string  // Теория и примеры
  },
  reward_json: { ... },
  linked_nodes: string[]
}
```

## Запуск миграции

Для повторного запуска миграции (если понадобится):

```bash
cd apps/api
npm run migrate:quests-structure
```

Скрипт автоматически:
- Пропускает квесты, которые уже имеют правильную структуру
- Обновляет только те квесты, которые нуждаются в реструктуризации
- Выводит детальную статистику

## Технические детали

### Функции парсинга

Скрипт использует те же функции парсинга, что и для шаблонов:
- `parseDescription()` - разделяет описание на компоненты
- `findTheoryForQuest()` - находит теорию из quest-theories-mapping.json
- Поддержка форматов: "Шаги:" и "Подготовка/Встреча/После встречи"

### Безопасность

- Миграция не удаляет существующие данные
- Сохраняет теорию, если она уже есть в критериях
- Очищает только мусорные данные (одиночные буквы, пустые строки)
- Можно запускать многократно (идемпотентна)
