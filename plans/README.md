# Plans Directory

Эта папка содержит планы работы, созданные через Cursor Plans.

## Формат именования

Файлы планов должны использовать формат:
```
{описание}_ {id}.plan.md
```

Пример:
- `архитектурный_аудит_и_миграция_к_единому_источнику_истины_e5af5a72.plan.md`

## Структура плана

Каждый план должен содержать:
- **ID плана** - уникальный идентификатор
- **Дата создания** - дата создания плана
- **Статус** - текущий статус выполнения (В процессе / Завершен / Отложен)
- **Резюме проблемы** - описание проблемы или задачи
- **Целевая архитектура** - описание желаемого состояния
- **План миграции** - детальные шаги с чекбоксами статусов
- **Текущий статус** - что выполнено, что в процессе, что запланировано
- **Критерии успешной миграции** - критерии завершения

## Статусы задач

- ✅ - Выполнено
- ⏳ - В процессе
- 📋 - Запланировано
- ❌ - Отменено

## Автоматическое сохранение

При создании или обновлении плана в Cursor:
1. Файл автоматически сохраняется в эту папку
2. Файл должен быть закоммичен в git
3. При обновлении плана обновляется дата "Последнее обновление"

---

**Важно:** Планы отслеживаются в git и должны быть закоммичены для сохранения истории.
