# Синхронизация квестов из шаблонов в базу данных

> **Контентная база:** 
> - `QUESTS_STRUCTURED_CONTENT.md` — полное структурированное описание всех квестов
> - `QUESTS_THEORIES_MAPPING.md` — полный маппинг теоретических блоков
> - `data/quest-templates.json` — JSON-версия данных (синхронизируется с MD файлами)

## Источник данных

Контент квестов хранится в:
- **MD файлы** (контентная база): `QUESTS_STRUCTURED_CONTENT.md` и `QUESTS_THEORIES_MAPPING.md`
- **JSON файл** (для синхронизации): `data/quest-templates.json`

JSON файл синхронизируется с MD файлами через скрипт `generate-structured-quests-md.py`.

## Структура данных

Все квесты структурированы согласно `docs/quests/QUEST_CONTENT_STRUCTURE.md`:
- ✅ `description` — только краткое описание цели (без этапов, критериев, награды)
- ✅ `steps` — структурированные шаги выполнения
- ✅ `criteria.items` — проверяемые критерии успеха
- ✅ `criteria.theory_and_examples` — полная теория (синхронизируется из `QUESTS_THEORIES_MAPPING.md`)

### 2. Обновление квестов в базе данных

Есть два способа обновить квесты в базе данных:

#### Способ 1: Через API (рекомендуется)

```bash
# Обновить теории всех квестов
python scripts/update-quests-theory-api.py --api-url http://localhost:3001

# Или с токеном аутентификации
python scripts/update-quests-theory-api.py --api-url http://localhost:3001 --token YOUR_TOKEN
```

#### Способ 2: Через прямой доступ к базе данных

Если у вас есть доступ к базе данных, можно обновить квесты напрямую через Prisma или SQL.

### 3. Проверка

После обновления проверьте в веб-интерфейсе:
1. **Описание** должно быть кратким (без этапов, критериев, награды)
2. **Шаги выполнения** должны быть структурированы (отдельные шаги с заголовками)
3. **Теория** должна содержать полную теорию из `QUESTS_THEORIES_MAPPING.md`
4. **Критерии успеха** должны быть в отдельном блоке

## Структура правильного квеста

```json
{
  "id": "story_путь_к_субъектности_27",
  "title": "Путь к субъектности",
  "description": "Исследуйте переход от реактивного поведения к действию из субъектности. Развивайте способность удерживать позицию и создавать новые возможности.",
  "type": "story",
  "steps": [
    {
      "order": 1,
      "title": "Этап 1: Диагностика (Неделя 1-2)",
      "description": "Проанализируйте 5 ситуаций из прошлого месяца..."
    },
    {
      "order": 2,
      "title": "Этап 2: Практика удержания позиции (Неделя 3)",
      "description": "Выберите 3 ситуации..."
    }
  ],
  "criteria": {
    "type": "custom",
    "items": [
      "Проанализированы минимум 5 ситуаций",
      "Практиковано удержание позиции минимум в 3 ситуациях"
    ],
    "theory_and_examples": "## Что такое путь к субъектности\n\n..."
  }
}
```

## Примечания

- Квесты в базе данных могут быть созданы пользователями и иметь другой `userId`
- При обновлении через API убедитесь, что у вас есть права на обновление квестов
- Если квест не найден в базе, его нужно создать вручную или через процесс создания квестов из шаблонов
