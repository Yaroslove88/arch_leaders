# Индекс документации по квестам

Этот документ содержит полный список всех файлов документации, связанных с описанием, наполнением и разработкой квестов в проекте.

> **⚠️ ВАЖНО: Контентная база квестов (основа для всех данных):**
> 1. **`QUESTS_STRUCTURED_CONTENT.md`** — полное структурированное описание всех квестов (без теории)
> 2. **`QUESTS_THEORIES_MAPPING.md`** — полный маппинг всех квестов с их теоретическими блоками
>
> Эти два файла являются **контентной базой** проекта по квестам. Все остальные документы и данные должны соответствовать им.
>
> **Методологические основы:**
> 1. **`docs/QUEST_CONTENT_STRUCTURE.md`** — определяет структуру всех полей квеста и правила распределения информации
> 2. **`docs/QUEST_THEORY_EXAMPLES.md`** — содержит готовые примеры теоретических блоков для всех типов квестов

## 📋 Контентная база квестов (ОСНОВА)

### ⭐ **QUESTS_STRUCTURED_CONTENT.md** (КОНТЕНТНАЯ БАЗА №1)
   - **Описание:** Полное структурированное описание всех квестов проекта
   - **Содержание:** Все 33 квеста (19 micro, 5 weekly, 4 story, 5 in-person) со структурой:
     - Описание
     - Шаги выполнения
     - Критерии успеха
     - Награда
     - Связанные способности
   - **Теория:** Не включена (см. `QUESTS_THEORIES_MAPPING.md`)
   - **Использование:** Основной справочник по структуре и содержанию квестов, источник для синхронизации с БД
   - **Статус:** Контентная база, источник истины для всех квестов

### ⭐ **QUESTS_THEORIES_MAPPING.md** (КОНТЕНТНАЯ БАЗА №2)
   - **Описание:** Полный маппинг всех квестов с их теоретическими блоками
   - **Содержание:** Все 33 квеста с полными теоретическими блоками (`theory_and_examples`) в формате Markdown
   - **Использование:** Справочник для поиска теории по конкретному квесту, источник для синхронизации с базой данных
   - **Статус:** Контентная база, источник истины для теоретических блоков

## 📐 Методологические документы

### ⭐ **docs/QUEST_CONTENT_STRUCTURE.md** (МЕТОДОЛОГИЯ №1)
   - **Описание:** Окончательная структура контента квестов
   - **Содержание:** Определяет структуру всех полей квеста, их назначение, формат и правила распределения информации
   - **Использование:** Основной справочник по структуре данных квестов, правила избежания дублирования
   - **Статус:** Окончательная версия, определяет методологию структурирования

### ⭐ **docs/QUEST_THEORY_EXAMPLES.md** (МЕТОДОЛОГИЯ №2)
   - **Описание:** Окончательные примеры теоретических блоков
   - **Содержание:** Готовые примеры правильно оформленных теорий для всех типов квестов
   - **Использование:** Референс для создания новых теорий, шаблоны для заполнения theory_and_examples
   - **Статус:** Окончательная версия, содержит структуру теоретического блока

### 1. **ENHANCE_QUESTS_THEORIES.md**
   - **Описание:** Определяет структуру и требования для теоретических блоков (`theory_and_examples`) в квестах
   - **Содержание:** Детальная структура теоретического блока, требования к содержанию, примеры
   - **Использование:** Руководство для создания и заполнения теоретических блоков для каждого квеста
   - **Примечание:** Подчинен `docs/QUEST_CONTENT_STRUCTURE.md` и `docs/QUEST_THEORY_EXAMPLES.md`

### 3. **docs/QUEST_THEORY_GENERATION_LOGIC.md**
   - **Описание:** Логика генерации теоретических блоков
   - **Содержание:** Алгоритмы и правила создания теорий для квестов
   - **Использование:** Техническая документация для автоматической генерации контента

### 4. **docs/QUEST_THEORY_GENERATION_PROMPT.md**
   - **Описание:** Промпты для генерации теорий квестов
   - **Содержание:** Шаблоны промптов для AI-генерации теоретических блоков
   - **Использование:** Инструмент для автоматической генерации контента
   - **Примечание:** Должен использовать структуру из `QUEST_CONTENT_STRUCTURE.md` и примеры из `QUEST_THEORY_EXAMPLES.md`

### 5. **docs/UPDATE_QUEST_THEORIES.md**
   - **Описание:** Инструкции по обновлению теорий квестов
   - **Содержание:** Процесс обновления теоретических блоков в системе
   - **Использование:** Руководство для обновления контента

## 🎯 Рекомендуемый порядок изучения

1. **Для работы с контентом квестов (НАЧНИТЕ ОТСЮДА):**
   - ⭐ `QUESTS_STRUCTURED_CONTENT.md` — **КОНТЕНТНАЯ БАЗА: все квесты со структурой**
   - ⭐ `QUESTS_THEORIES_MAPPING.md` — **КОНТЕНТНАЯ БАЗА: все теоретические блоки**
   - `data/quest-templates.json` — JSON-версия данных (синхронизируется с MD файлами)

2. **Для понимания методологии структурирования:**
   - ⭐ `docs/QUEST_CONTENT_STRUCTURE.md` — **МЕТОДОЛОГИЯ: правила структуры**
   - ⭐ `docs/QUEST_THEORY_EXAMPLES.md` — **МЕТОДОЛОГИЯ: примеры теорий**
   - `ENHANCE_QUESTS_THEORIES.md` (руководство по заполнению, подчинено методологическим документам)

3. **Для генерации и обновления контента:**
   - `docs/QUEST_THEORY_GENERATION_PROMPT.md` (промпты для AI-генерации)
   - `docs/QUEST_THEORY_GENERATION_LOGIC.md` (логика генерации)

3. **Для синхронизации данных:**
   - `scripts/README_QUEST_SYNC.md`

4. **Для разработки UI:**
   - `docs/QUESTS_UX_UI_SPECIFICATION.md`
   - `QUESTS_UI_IMPROVEMENTS.md`

5. **При возникновении проблем:**
   - `QUESTS_TROUBLESHOOTING.md`
   - `ERROR_FIX_QUESTS_SESSIONS.md`

## 📝 Связанные файлы данных

Помимо документации, контент квестов хранится в:
- `data/quest-templates.json` - JSON-шаблоны всех квестов
- `data/quest-templates-enhanced.json` - Расширенные шаблоны
- `data/quest-templates-restructured.json` - Переструктурированные шаблоны
- `data/quest-theories-mapping.json` - JSON-версия маппинга теорий
