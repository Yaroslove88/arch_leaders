# Контентная база квестов

> **Статус:** Активная контентная база проекта

## 📚 Источники истины

Два файла являются **контентной базой** проекта по квестам:

### 1. **QUESTS_STRUCTURED_CONTENT.md**
- Полное структурированное описание всех 33 квестов
- Содержит: описание, шаги выполнения, критерии успеха, награда, связанные способности
- **НЕ содержит теорию** (см. `QUESTS_THEORIES_MAPPING.md`)
- Источник истины для структуры и содержания квестов

### 2. **QUESTS_THEORIES_MAPPING.md**
- Полный маппинг всех квестов с их теоретическими блоками
- Содержит полные тексты `theory_and_examples` для всех квестов
- Источник истины для теоретических блоков

## 🔄 Синхронизация данных

### JSON файл: `data/quest-templates.json`
- JSON-версия данных, синхронизируется с MD файлами
- Используется для синхронизации с базой данных через API
- Генерируется из MD файлов через скрипт `scripts/generate-structured-quests-md.py`

### Синхронизация с базой данных

```bash
# Вариант 1: Массовая синхронизация (быстрее)
python scripts/sync-quests-batch.py

# Вариант 2: Пошаговая синхронизация (с детальным логом)
python scripts/sync-all-quests-from-templates.py
```

Подробнее: `scripts/SYNC_QUESTS_GUIDE.md`

## 📐 Методологические основы

Структура контента определяется:

1. **`docs/QUEST_CONTENT_STRUCTURE.md`** — правила структурирования данных
2. **`docs/QUEST_THEORY_EXAMPLES.md`** — примеры теоретических блоков

## 🎯 Использование

- **Для работы с контентом:** Используйте `QUESTS_STRUCTURED_CONTENT.md` и `QUESTS_THEORIES_MAPPING.md`
- **Для синхронизации:** Используйте `data/quest-templates.json`
- **Для разработки:** Следуйте методологии из `docs/QUEST_CONTENT_STRUCTURE.md`

## 📝 Обновление контента

1. Обновите соответствующий MD файл (`QUESTS_STRUCTURED_CONTENT.md` или `QUESTS_THEORIES_MAPPING.md`)
2. Обновите `data/quest-templates.json` (если нужно)
3. Синхронизируйте с БД через API (см. `scripts/SYNC_QUESTS_GUIDE.md`)
