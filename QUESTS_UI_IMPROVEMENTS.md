# Улучшения UI квестов

## Выполненные изменения

### 1. ✅ Улучшено описание
- Описание теперь более подробное
- Автоматически добавляется информация о количестве шагов
- Контекст о развитии способностей через практику

### 2. ✅ Блок "Теория" перемещен под описание
- Теория теперь находится сразу после блока описания
- Улучшено отображение с пояснением назначения
- Убрано дублирование информации из других блоков
- Теория содержит:
  - Детальное объяснение способности
  - Пояснение терминов
  - Обоснование важности
  - Примеры применения
- Добавлен вступительный текст, объясняющий, что содержит теория

### 3. ✅ Блок "Почему появился этот квест" перемещен
- Перемещен под блок "Награда"
- Источники теперь отображаются на русском языке:
  - `session_analysis` → "Анализ ситуации"
  - `base_template` → "Базовый шаблон"
  - `manual` → "Создан вручную"
  - `auto-generated` → "Автоматически сгенерирован"

### 4. ✅ Кнопка "Активировать квест" перенесена
- Теперь находится в правом верхнем углу блока описания
- Блок "Действия" убран для квестов в статусе `backlog`
- Для активных квестов остался упрощенный блок "Действия" с кнопками:
  - "Добавить доказательство"
  - "Завершить квест"

## Новая структура отображения

```
1. Заголовок и статус
2. Описание (с кнопкой активации справа вверху для backlog)
3. Теория (скрывается/показывается)
4. Гипотеза (если есть)
5. Шаги выполнения
6. Критерии успеха
7. Связанные способности
8. Награда
9. Почему появился этот квест (перемещен сюда)
10. Возможные компромиссы (если есть)
11. Доказательства
12. Действия (только для активных квестов)
```

## Технические детали

### Функция перевода источника
```typescript
function translateSource(source: string | null | undefined): string {
  const sourceMap: Record<string, string> = {
    'session_analysis': 'Анализ ситуации',
    'base_template': 'Базовый шаблон',
    'manual': 'Создан вручную',
    'auto-generated': 'Автоматически сгенерирован',
  };
  return sourceMap[source] || source;
}
```

### Улучшенное описание
- Автоматически дополняется информацией о количестве шагов
- Добавляется контекст о развитии способностей
- Более подробное и информативное

### Теория без дублирования
- Проверка на дублирование с шагами
- Фокус на пояснении терминов и обосновании
- Детальные примеры и практика
