# Изображения для страницы онбординга

Эта папка содержит изображения для страницы `/introduce`.

## Необходимые изображения

| Файл | Размер | Описание |
|------|--------|----------|
| `author-photo.jpg` | 200x200 | Фото автора курса (основное, круглое) |
| `author-photo-small.jpg` | 100x100 | Фото автора (маленькое для CTA) |
| `concept-architecture.svg` | 400x300 | Иллюстрация концепции архитектурного лидерства |
| `tree-preview.svg` | 400x300 | Превью дерева способностей |
| `cycle-diagram.svg` | 600x200 | Схема цикла развития |

## Иконки веток (папка `branches/`)

| Файл | Размер | Ветка |
|------|--------|-------|
| `subjectivity.svg` | 64x64 | Субъектность 🧠 |
| `architectural.svg` | 64x64 | Архитектурное мышление 🧱 |
| `responsibility.svg` | 64x64 | Ответственность ⚖️ |
| `maturity.svg` | 64x64 | Среда зрелости 🌱 |
| `resilience.svg` | 64x64 | Устойчивость ⚡ |
| `feedback.svg` | 64x64 | Обратная связь 🔄 |

## Как добавить изображения

1. Подготовьте изображения в указанных размерах
2. Положите их в соответствующие папки
3. Страница автоматически подхватит изображения

## Fallback

Пока изображения не добавлены, на странице отображаются placeholder'ы с эмодзи.
