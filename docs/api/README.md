## Логика именования файлов

Все файлы документации по API именуются по следующей логике:

```
<ТЕМА>_<ТИП>.md
```

**Где:**
- `<ТЕМА>` — тема документа (API)
- `<ТИП>` — тип документа (DOCUMENTATION)

---

## Связанные файлы

### Код

**Backend:**
- `apps/api/src/*/controllers/` — все контроллеры с endpoints
- `apps/api/src/*/dto/` — Data Transfer Objects
- Swagger документация доступна по адресу `/api/docs` (если настроено)

**Frontend:**
- `apps/web/src/lib/api.ts` — клиент API для фронтенда
