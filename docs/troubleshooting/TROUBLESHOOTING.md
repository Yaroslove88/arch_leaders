# Устранение неполадок

## Проблема: Не отображаются узлы, квесты или кейсы в веб-интерфейсе

### Проверка 1: API сервер запущен

Убедитесь, что API сервер запущен:
```bash
cd apps/api
npm run start:dev
```

API должен быть доступен на `http://localhost:3001`

### Проверка 2: Веб-приложение запущено

Убедитесь, что веб-приложение запущено:
```bash
cd apps/web
npm run dev
```

Веб должен быть доступен на `http://localhost:3000`

### Проверка 3: Переменная окружения API_URL

Проверьте, что в `.env.local` (или `.env`) файле веб-приложения указан правильный URL API:

```env
NEXT_PUBLIC_API_URL=http://localhost:3001
```

### Проверка 4: Файлы данных существуют

Убедитесь, что файлы данных находятся в правильных местах:

- `leadership-architect/data/interactive-cases.json` - должен содержать массив `interactive_cases`
- `leadership-architect/data/node-descriptions.json` - должен содержать объект `node_descriptions`
- `leadership-architect/packages/shared/src/seed/initial-ability-tree.json` - должен содержать дерево с узлами

### Проверка 5: Проверка API endpoints вручную

Откройте в браузере:
- `http://localhost:3001/tree/semantic` - должно вернуть дерево с узлами
- `http://localhost:3001/cases` - должно вернуть список кейсов
- `http://localhost:3001/nodes/descriptions` - должно вернуть описания узлов
- `http://localhost:3001/quests` - должно вернуть список квестов

### Проверка 6: Консоль браузера

Откройте DevTools (F12) и проверьте:
1. Вкладка Console - есть ли ошибки?
2. Вкладка Network - выполняются ли запросы к API? Какие статусы ответов?

### Проверка 7: Логи API сервера

Проверьте логи API сервера на наличие ошибок:
- Ошибки загрузки файлов
- Ошибки парсинга JSON
- Ошибки путей к файлам

### Типичные ошибки:

1. **"Failed to load tree"** - API не отвечает или seed файл не найден
2. **"Failed to load cases"** - файл `interactive-cases.json` не найден или имеет неправильный формат
3. **"Failed to load node descriptions"** - файл `node-descriptions.json` не найден
4. **CORS ошибки** - проверьте настройки CORS в API
5. **404 Not Found** - endpoint не зарегистрирован, проверьте `app.module.ts`

### Решение проблем:

1. **Перезапустите API сервер** после изменений в модулях
2. **Проверьте пути к файлам** - они должны быть относительно корня проекта `leadership-architect`
3. **Проверьте формат JSON** - файлы должны быть валидным JSON
4. **Очистите кеш браузера** и перезагрузите страницу
5. **Проверьте логи** в консоли браузера и терминале API

### Диагностика:

В консоли браузера должны появиться логи:
- `Tree loaded:` - при успешной загрузке дерева
- `Cases loaded: X` - количество загруженных кейсов
- `Quests loaded: X` - количество загруженных квестов
- `Branches: X, Nodes: Y` - количество веток и узлов

Если этих логов нет, значит запросы не выполняются или возвращают ошибки.
