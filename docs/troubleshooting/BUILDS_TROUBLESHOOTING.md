# Решение проблемы с наборами квестов (Builds)

## Дата: 2026-01-07

## Проблема

После `pnpm prisma migrate reset` узлы появились (40 узлов), но наборы квестов (builds) не отображаются.

## Диагностика

### 1. Файл builds.json существует
- ✅ Файл находится в `data/builds.json`
- ✅ Содержит 4 билда:
  - `build_crisis_solver` - Кризисный решатель
  - `build_architect` - Архитектор системы
  - `build_developing_leader` - Развивающий лидер
  - `build_strategist` - Стратег

### 2. Проблема с активацией билдов

**Причина:** После `prisma migrate reset` все узлы в дереве находятся в состоянии `locked` или `available`, а не `active`/`unlocked`/`integrated`.

**Логика активации билдов:**
- Билд активируется, если у пользователя есть активные/разблокированные узлы, которые соответствуют `required_nodes` билда
- Минимум `min_required_count` узлов из `required_nodes` должны быть активны
- Опциональные узлы (`optional_nodes`) дают дополнительный бонус к активации, но не обязательны
- Если нет активных узлов → все билды имеют 0% активации → не отображаются как активные

## Решение

### Вариант 1: Разблокировать узлы вручную (для тестирования)

1. Создайте записи (entries) через API или UI
2. Запустите анализ сессий
3. Узлы автоматически разблокируются при накоплении XP

### Вариант 2: Проверить все билды (не только активные)

Измените фронтенд, чтобы показывать все билды, а не только активные:

```typescript

const activeBuilds = currentBuilds?.filter((b: any) => b.is_active) || [];

// Показывайте все билды с их процентом активации
const allBuilds = currentBuilds || [];
```
