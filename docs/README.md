## 📋 Логика организации

Документация организована по принципу **"одна тема — одна папка"**:

- Каждая папка содержит README.md с описанием структуры
- Актуальные документы находятся в соответствующих папках
- Устаревшие документы перемещены в `archive/`
- Контентная база (данные) остается в корне проекта

### 📐 Правила создания документов

⚠️ **ВАЖНО:** При создании нового документа следуйте правилам автоматической классификации:

- **[DOCUMENTATION_RULES.md](./DOCUMENTATION_RULES.md)** — быстрая справка
- **[.cursorrules-documentation.md](../.cursorrules-documentation.md)** — полные правила

**Принцип:** Документы автоматически размещаются в соответствующих папках на основе ключевых слов в названии файла.

---

## 🔄 Обновление документации

При внесении изменений в систему:

1. **Обновите соответствующий документ** в тематической папке
2. **Обновите README.md** папки, если структура изменилась
3. **Устаревшие документы** переместите в `archive/`
