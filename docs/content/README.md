# Документация по контенту

> **Дата последнего обновления:** 15.01.2025  
> **Статус:** Актуальная

Этот каталог содержит документацию по контенту проекта: игровой контент, промпты для изображений, руководства по использованию.

---

## Структура документации

### 📋 Основные документы

1. **[GAME_CONTENT.md](./GAME_CONTENT.md)**
   - **Часть системы:** Игровой контент
   - **Содержание:** User Flow, каталог квестов, ветки квестов, описания узлов, кейсы и ситуации
   - **Статус:** ✅ Актуальна (полный каталог контента)

2. **[CONTENT_BASE_README.md](./CONTENT_BASE_README.md)**
   - **Часть системы:** Руководство по контентной базе
   - **Содержание:** Описание контентной базы проекта, источники данных, методология
   - **Статус:** ✅ Актуальна (руководство)

3. **[CONTENT_USAGE_GUIDE.md](./CONTENT_USAGE_GUIDE.md)**
   - **Часть системы:** Руководство по использованию контента
   - **Содержание:** Как использовать контентную базу, синхронизация, обновление
   - **Статус:** ✅ Актуальна

4. **[CONTENT_UPDATE_SUMMARY.md](./CONTENT_UPDATE_SUMMARY.md)**
   - **Часть системы:** Сводка обновлений контента
   - **Содержание:** История обновлений контентной базы
   - **Статус:** ✅ Актуальна (исторический документ)

5. **[Промпты для изображений](../design-system/IMAGE_GENERATION_PROMPTS.md)**
   - **Часть системы:** Промпты для генерации изображений всех элементов
   - **Расположение:** `docs/design-system/IMAGE_GENERATION_PROMPTS.md`
   - **Содержание:** Единый актуальный источник промптов для веток, узлов, билдов, заглушек
   - **Статус:** ✅ Актуальна (использует новую цветовую систему)
   - **Примечание:** Все промпты теперь находятся в `docs/design-system/`. Старые документы перемещены в архив.

## Логика именования файлов

Все файлы документации по контенту именуются по следующей логике:

```
<ТЕМА>_<ТИП>.md
```

**Где:**
- `<ТЕМА>` — тема документа (GAME_CONTENT, CONTENT_BASE, CONTENT_USAGE, CONTENT_UPDATE)
- `<ТИП>` — тип документа (README, GUIDE, SUMMARY)

**Примечание:** Промпты для генерации изображений теперь находятся в `docs/design-system/IMAGE_GENERATION_PROMPTS.md`

## Связанные файлы

### Контентная база (в корне проекта)

- `QUESTS_STRUCTURED_CONTENT.md` — структурированный контент квестов
- `QUESTS_THEORIES_MAPPING.md` — маппинг теорий квестов
- `00_кейсы.md` — описание кейсов

### Данные

- `data/interactive-cases.json` — JSON файл с кейсами
- `data/quest-templates.json` — JSON шаблоны квестов
- `data/semantic-tree.json` — дерево способностей

## Быстрый старт

1. **Для работы с игровым контентом:**
   - Изучите [GAME_CONTENT.md](./GAME_CONTENT.md)

2. **Для понимания контентной базы:**
   - Начните с [CONTENT_BASE_README.md](./CONTENT_BASE_README.md)

3. **Для использования контента:**
   - Используйте [CONTENT_USAGE_GUIDE.md](./CONTENT_USAGE_GUIDE.md)

4. **Для генерации изображений:**
   - См. [IMAGE_GENERATION_PROMPTS.md](../design-system/IMAGE_GENERATION_PROMPTS.md) — единый актуальный источник всех промптов

---

## Обновление документации

При обновлении контента:

- **Новый игровой контент** → обновить `GAME_CONTENT.md`
- **Изменения в методологии** → обновить `CONTENT_BASE_README.md`
- **Новые промпты для изображений** → добавить в `docs/design-system/IMAGE_GENERATION_PROMPTS.md`
