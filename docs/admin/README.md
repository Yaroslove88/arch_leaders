## Логика именования файлов

Все файлы документации по админ-панели именуются по следующей логике:

```
ADMIN_<ЧАСТЬ_СИСТЕМЫ>.md
```

**Где:**
- `ADMIN` — префикс для всех файлов документации по админке
- `<ЧАСТЬ_СИСТЕМЫ>` — описание части системы (PANEL, MODE, SCHEMA_API)

## Связанные файлы

### Код

**Backend:**
- `apps/api/src/admin/` — модуль админ-панели
- `apps/api/src/admin/admin.service.ts` — сервис админки
- `apps/api/src/admin/admin.controller.ts` — REST API контроллер

**Frontend:**
- `apps/web/src/components/AdminPanel.tsx` — компонент админ-панели
- `apps/web/src/components/AdminDebugPanel.tsx` — отладочная панель
- `apps/web/src/components/AdminToggle.tsx` — переключатель режима админа
- `apps/web/src/lib/admin.ts` — функции для работы с админ-режимом

## Обновление документации

При внесении изменений в админ-панель обновляйте соответствующую документацию:

- **Изменения в функциональности** → обновить `ADMIN_PANEL_IMPLEMENTATION.md`
- **Изменения в API** → обновить `ADMIN_SCHEMA_API.md`
- **Новые функции режима админа** → обновить `ADMIN_MODE.md`
