## Примененные стили Architectural Dark

### Цветовая палитра
- **Фоны:** `bg-bg-main`, `bg-bg-secondary`, `bg-bg-panel`, `bg-bg-canvas`
- **Текст:** `text-ui-text-main`, `text-ui-text-muted`, `text-ui-text-dim`
- **Границы:** `border-ui-border-soft`, `border-ui-border-strong`
- **Системные цвета:**
  - `system-focus` — основной акцент
  - `system-growth` — успех/завершение
  - `system-warning` — предупреждения
  - `system-critical` — ошибки
  - `system-stable` — стабильность (админ)

### Тени
- `shadow-panel` — для карточек
- `shadow-floating` — для модальных окон и плавающих элементов
- `shadow-active` — для активных состояний

### Интерактивные элементы
- Кнопки с `focus:ring-2 focus:ring-system-focus`
- Hover состояния: `hover:bg-system-focus/80`
- Переходы: `transition-colors`
