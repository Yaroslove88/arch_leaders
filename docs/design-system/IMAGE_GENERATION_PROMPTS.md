# 🎨 VISUAL STYLE MODIFIERS

**(вставляются сразу после system prompt)**

## Философия визуального языка

**Ключевая формула:** McKinsey-level intellect × psychological depth × modern leadership × architectural thinking

**Смысл, который должен ощущаться визуально:**
- Здесь понимают сложность — изображения показывают многоуровневые системы, не упрощая
- Здесь работают с мышлением — акцент на структуры, связи, паттерны, а не на поверхностные действия
- Здесь развивают субъектность — визуальный язык уважает внутренний мир и глубину личности
- Здесь формируют лидеров — ощущение стратегической среды, пространства принятия решений
- Здесь не учат — здесь перестраивают — визуалы показывают трансформацию структур, не инструкции
- Здесь не мотивируют — здесь ориентируют — навигация в сложности, а не призывы к действию

**Архетип визуального бренда:**
- Primary: The Sage Strategist (советник первых лиц)
- Secondary: The Architect Mentor (архитектор систем, наставник зрелости)

## Общий стиль сцены

> "Architectural composition, strong structure, depth, balance, and hierarchy. Premium color grading, slightly warm highlights, deep shadows, soft contrast. Sense of scale, clarity, and inner order. Visual intelligence over decoration. Strategic systems over simple illustrations. Deep space suggests complexity and potential, not emptiness. Structures imply thinking and frameworks, not just objects."

## Цвет и атмосфера

> "Dark obsidian and graphite base, strategic deep blue and muted violet tones, subtle gold or amber accents for meaning and progression, no bright saturated colors, no cartoon look. Colors carry meaning: blue = strategy and intelligence, violet = subjectivity and depth, green = integration and growth, red = challenges and transformation, gold = value and level, amber = warmth and humanity."

**Цветовая палитра проекта:**

**Foundation Colors (70-80% интерфейса):**
- Obsidian Core: `#0F1216` — Главный фон. Пространство мышления. Потенциал. Глубина.
- Graphite Structure: `#1A1F26` — Архитектурная подложка. Контейнеры. Карточки.
- Ash Light: `#E6E8EB` — Интеллектуальный "белый". Чтение. Структура. Воздух.

**Core Meaning Colors (системные):**
- Strategic Blue: `#1F3A5F` — Стратегия, мышление, интеллект, архитектура
- Inner Violet: `#3B2F4A` — Субъектность, глубина, рефлексия, личность
- Sage Green: `#4E6F5D` — Интеграция, рост, устойчивость
- Tension Red: `#8C2F2F` — Вызовы, кризисы, точки напряжения

**Accent/Power Colors (5-10% интерфейса):**
- Catalyst Gold: `#C6A75E` — Ценность. Уровень. Переход. Инициация. CTA, маркеры, уровни, награды
- Warm Amber: `#B8743A` — Тепло. Контакт. Человечность. Присутствие. Цитаты, истории, рефлексивные зоны

## Эмоциональный тон

> "Emotionally mature, psychologically warm but intellectually sharp. Calm presence, inner strength, reflection, and authority. The site should feel like: 'A place where people think better and deeper. And where you can grow without losing dignity.' Not therapeutic, not gamified, not motivational — strategic, architectural, developmental."

# 📱 ИСПОЛЬЗОВАНИЕ СМАЙЛИКОВ И ИКОНОК В ИНТЕРФЕЙСЕ

## Философия использования смайликов

**Принцип:** Смайлики и эмодзи должны служить функциональной цели (семантическая маркировка, категоризация) и не удешевлять интерфейс. В элитарном интеллектуальном продукте уровень McKinsey-level каждый элемент должен нести смысл.

**Ключевое правило:** Используем смайлики как семантические маркеры, а не декоративные элементы. Они должны помочь быстро категоризировать и ориентироваться в контенте, не создавая ощущения "игрового" или "незрелого" интерфейса.

## ✅ Где УМЕСТНО использовать смайлики

### 1. Семантическая категоризация контента

**Ветки развития (иконки-идентификаторы):**
- 🌿 Субъектность
- 🧱 Архитектурное мышление
- ⚖️ Ответственность
- 🌱 Среда зрелости
- ⚡ Устойчивость
- 💬 Обратная связь

**Типы контента (категоризация):**
- ⚔️ Квесты (эксперименты для практики)
- 📊 Кейсы (ситуации для анализа)
- 📝 Ситуации (записи пользователя)
- 👁️ Доказательства (следы практики)
- 🪞 Рефлексия (размышления)

**Типы развития узлов:**
- 🎯 Practice (практический)
- 🪞 Reflection (рефлексивный)
- 📚 Theory (теоретический)
- 🔄 Mixed (смешанный)

**Уровни интеграции:**
- 🌱 Новичок (Novice)
- 🌿 Интегрировано (Integrated)
- 🌳 Воплощено (Embodied)

### 2. Статусы и состояния (функциональная маркировка)

**Статусы узлов:**
- 🔒 Заблокирован (locked)
- 🔵 Доступен (available)
- ⚪ В работе (active)
- ✅ Разблокирован (unlocked)
- ⭐ Интегрирован (integrated)

**Статусы квестов:**
- ✅ Завершён
- 🔵 В процессе
- ⚪ Отложен
- 🔒 Заблокирован

**Индикаторы важности/внимания:**
- ⚡ Текущий фокус / срочное действие
- ⚠️ Предупреждение / внимание
- 💡 Подсказка / инсайт
- 🎯 Рекомендация

### 3. Структурные разделители в контенте

**Секции в детальных карточках:**
- 📝 Гипотеза (в квестах)
- ⚡ Крючок (в кейсах)
- 📊 Данные (в кейсах)
- ⚠️ Дилемма (в кейсах)
- 💡 Ключевой инсайт (в кейсах)
- 🪞 Рефлексия / Вопрос для рефлексии
- 🌳 Развивает / Влияние на дерево
- 🗺️ Путь выполнения (в квестах)
- 📎 Доказательства

**Использование:** В детальных карточках смайлики помогают быстро сканировать структуру длинного контента.

### 4. Навигационные элементы (ограниченно)

- Используем только в административных интерфейсах для быстрой категоризации (📊 Обзор, 📝 Контент, ⚙️ Задачи, 🔒 Аудит)
- В пользовательской навигации предпочитаем текст или SVG-иконки

## ❌ Где НЕУМЕСТНО использовать смайлики

### 1. Основные заголовки страниц
**Неправильно:**
```
🎯 Архитектура способностей
⚔️ Мои квесты
📊 Кейсы для анализа
```

**Правильно:**
```
Архитектура способностей
Эксперименты
```

### 2. Основные CTA-кнопки
**Неправильно:**
```
[🎯 Начать квест]
[📝 Добавить ситуацию]
```

**Правильно:**
```
[Начать квест]
[Добавить ситуацию]
```

Или используем SVG-иконки вместо эмодзи.

### 3. Основной текст и описания
**Неправильно:**
```
Субъектность 🌿 — это способность видеть внутренний мир других людей.
```

**Правильно:**
```
Субъектность — это способность видеть внутренний мир других людей.
```
*(Смайлик может быть только в заголовке секции или в карточке как идентификатор)*

### 4. Ошибки и системные сообщения
**Неправильно:**
```
❌ Ошибка загрузки
⚠️ Что-то пошло не так
```

**Правильно:**
```
Ошибка загрузки
Внимание: Что-то пошло не так
```
*(Используем цветовую индикацию и типографику вместо смайликов)*

### 5. Формы и поля ввода
**Неправильно:**
```
💬 Опишите ситуацию...
📝 Ваши мысли...
```

**Правильно:**
```
Опишите ситуацию...
Ваши мысли...
```

## 🎨 Рекомендации по использованию

### Размер и стиль

1. **Размер:** Смайлики в интерфейсе должны быть не больше основного текста или заголовка (обычно `text-base`, `text-lg`, `text-xl` для заголовков секций)

2. **Частота:** Один смайлик на элемент. Избегаем цепочек: ❌ `⚔️📊🎯 Квесты` ✅ `⚔️ Квесты`

3. **Консистентность:** Используем одни и те же смайлики для одних и тех же категорий во всём приложении

4. **Цвет:** Смайлики наследуют цвет текста (currentColor). Не используем цветные эмодзи-варианты.

### Альтернатива: SVG-иконки

Когда смайлик неуместен, используем SVG-иконки:
- В навигации (вместо эмодзи)
- В основных CTA-кнопках
- В карточках как основной визуальный элемент
- Для статусов, где нужна более точная визуальная коммуникация

**Процесс:** См. секцию "Промпты для генерации SVG-иконок" ниже.
