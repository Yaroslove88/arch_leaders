## 📋 Принципы применения

### Цвета
- **80% экрана** - базовые цвета (bg-main, bg-panel, ui-text-*)
- **System colors** - только для событий и состояний
- **Максимум 2 акцента** на одном экране

### Тени
- **Panel/Card** - shadow-panel
- **Floating** - shadow-floating (модалки, карточки узлов)
- **Active** - shadow-active (выбранные элементы)

### Типографика
- Заголовки: увеличенный line-height
- Тексты: спокойные, без маркетинга
- Мета: уменьшенный размер, muted цвет

### Формы
- Темный фон
- Тонкие рамки (ui-border-soft)
- Focus: system-focus с ring
- Placeholder: ui-text-dim
