## 🎯 Принципы применения

1. **Глубина вместо яркости** - тени создают слои (shadow-panel, shadow-floating, shadow-active)
2. **Контуры важнее заполнения** - тонкие рамки (ui-border-soft, ui-border-strong)
3. **Редкие акценты** - цвет = событие (system-* используются осознанно)
4. **Воздух** - большие поля пустоты
5. **Спокойствие** - низкий контраст, мягкие переходы

## 📝 Особенности реализации

### Тени
- Panel/Card: `shadow-panel`
- Floating: `shadow-floating` (модалки, карточки узлов)
- Active: `shadow-active` (выбранные элементы)

### Градиенты
- Панели: `bg-panel-gradient` (внутренний highlight)

### Состояния узлов
- Locked: полупрозрачный, без акцентов
- Available: мягкий свет (system-warning)
- Active: центр внимания (system-focus)
- Unlocked: спокойный (system-growth)
- Integrated: мягкое свечение (system-stable)
