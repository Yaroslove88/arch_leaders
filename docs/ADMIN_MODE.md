# Режим админа

## Описание

Режим админа позволяет:
- Видеть отладочную информацию на всех страницах
- Открывать все перки (способности) независимо от условий разблокировки
- Видеть все квесты независимо от статуса
- Получать детальную информацию об ошибках и структуре данных

## Как включить

### Способ 1: Через кнопку на странице

На любой странице нажмите кнопку переключения режима админа (обычно рядом с заголовком или в правом нижнем углу).

### Способ 2: Через глобальный переключатель

В правом нижнем углу экрана есть кнопка **ADMIN/USER** — нажмите её для переключения режима.

### Способ 3: Через переменную окружения

Установите переменную окружения:
```bash
NEXT_PUBLIC_ADMIN_MODE=true
```

### Способ 4: Через localStorage

В консоли браузера выполните:
```javascript
localStorage.setItem('admin_mode', 'true');
location.reload();
```

## Что доступно в режиме админа

### 1. Отладочная информация

На каждой странице отображаются панели отладки с детальной информацией:
- **Квесты**: список всех квестов, их статусы, наличие теории
- **Дерево способностей**: все узлы, их состояния, статистика
- **Билды**: информация о билдах и их активации
- **Доказательства**: статистика по типам доказательств

### 2. Лейбл "ADMIN"

На всех страницах отображается фиолетовый лейбл **ADMIN** рядом с заголовком.

### 3. Открытые перки

Все способности в дереве отображаются как **разблокированные** (unlocked), независимо от реального состояния.

### 4. Все квесты

Все квесты доступны для просмотра, независимо от условий разблокировки.

## Отключение режима

1. Нажмите кнопку переключения режима
2. Или выполните в консоли:
```javascript
localStorage.removeItem('admin_mode');
location.reload();
```

## Безопасность

⚠️ **Важно**: Режим админа работает только на клиенте и не влияет на безопасность сервера. 
Он предназначен только для отладки и разработки.

## Использование

Режим админа полезен для:
- Отладки проблем с отображением данных
- Проверки структуры данных
- Тестирования функциональности
- Просмотра всех квестов и способностей без прохождения игры
