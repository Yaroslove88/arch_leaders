## 🔍 Отладка

### Для веток "Архитектурное мышление" и "Среда зрелости"

Если иконки все еще не отображаются, проверьте в консоли браузера:
1. Откройте DevTools (F12)
2. Перейдите на вкладку Console
3. Найдите сообщения вида: `[BranchCard] No icon found for branchId: "..."`
4. Скопируйте точное значение `branchId` из лога

Затем обновите маппинг в `icon-utils.ts`, добавив точное значение `branchId`.
