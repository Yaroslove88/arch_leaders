## 1. Путь авторизации

### 1.1 Текущая реализация

| Компонент | Статус | Файл |
|-----------|--------|------|
| Страница `/login` | Done | `apps/web/src/app/login/page.tsx` |
| Telegram OAuth | Done | Backend: `auth.controller.ts`, Frontend: `login/page.tsx` |
| Telegram Mini App | Done | `TelegramWebAppProvider.tsx`, endpoint `/auth/telegram-webapp` |
| JWT токены | Done | 7-дневный срок жизни |
| Смена пароля (API) | Done | `PATCH /auth/change-password` |
| Удаление аккаунта (API) | Done | `DELETE /auth/me` |

### 1.2 Flow авторизации

```
Telegram OAuth:
User → Login Page → Telegram Widget → /auth/telegram → JWT → localStorage → /dashboard

Telegram Mini App:
User opens Mini App → TelegramWebAppProvider → /auth/telegram-webapp → JWT → Auto-auth
```

## 6. Приоритизация

### Sprint 1 — Критические гэпы (1-2 недели)

1. **Страница профиля** (`/profile`)
   - Основная информация пользователя
   - Форма смены пароля
   - Danger Zone (удаление аккаунта)

2. **Telegram Mini App fixes**
   - Редирект после авторизации
   - Обработка ошибок с UI feedback

3. **Онбординг в БД**
   - Добавить поле `onboarding_completed` в User
   - Миграция
   - API endpoint для обновления статуса

### Sprint 2 — Важные гэпы (2-3 недели)

4. **Автоактивация первого квеста**
   - После завершения онбординга
   - Или создание tutorial-квеста

5. **Редактирование записей**
   - Страница `/entries/[id]/edit`
   - Форма редактирования

6. **Подсказки для новых пользователей**
   - Тултипы на dashboard
   - Проверка `onboarding_completed`

### Sprint 3 — Улучшения (3-4 недели)

7. **Настройки профиля**
   - Уведомления
   - Экспорт данных

8. **Поиск и фильтрация**
   - Поиск по квестам
   - Фильтрация по статусу

9. **Улучшения дерева**
   - Связанные квесты в модальном окне
   - Визуализация связей
