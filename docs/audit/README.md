## Quick Wins (немедленные исправления)

Задачи с высоким impact и низким effort:

1. Заменить `router.back()` на явные ссылки в `/cases/[id]` (1h)
2. Добавить `<main>` на всех страницах (1h)
3. Logout в админке (2h)
4. Редирект после Mini App авторизации (2h)
5. Обработка ошибок Mini App (3h)
6. Focus trap в модальных окнах (3h)
7. UI активации промпта (4h)
8. Поле `onboarding_completed` в БД (4h)
9. Автоактивация первого квеста (4h)
