### 1. ✅ Убран пароль БД из docker-compose

**Проблема:** Пароль базы данных был захардкожен в `docker-compose.dev.yml`.

**Решение:**
- Пароль теперь берется из переменной окружения `POSTGRES_PASSWORD`
- Все параметры БД настраиваются через переменные окружения
- Добавлены значения по умолчанию для удобства разработки

**Файлы:**
- `infra/docker-compose.dev.yml` - обновлен для использования переменных окружения

### 2. ✅ Настроен CORS с белым списком

**Проблема:** CORS был включен без ограничений, разрешая запросы с любых доменов.

**Решение:**
- CORS настроен с белым списком доменов из `WEB_URL`
- В development режиме добавлены дополнительные origins для удобства
- Запросы без origin (Postman, curl) разрешены
- Настроены разрешенные методы и заголовки

**Файлы:**
- `apps/api/src/main.ts` - обновлена конфигурация CORS

## Как использовать

### Первоначальная настройка

1. Скопируйте `.env.example` в `.env`:
   ```bash
   # Linux/Mac
   cp .env.example .env
   
   # Windows PowerShell
   Copy-Item .env.example .env
   ```

2. Откройте `.env` и заполните значения:
   - **Обязательно измените** `POSTGRES_PASSWORD` на сильный пароль
   - Установите `DATABASE_URL` с правильным паролем
   - Добавьте хотя бы один LLM API ключ (OpenAI или Anthropic)

3. Запустите Docker Compose:
   ```bash
   docker-compose -f infra/docker-compose.dev.yml up -d
   ```
