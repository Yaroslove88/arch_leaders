# Документация по аутентификации и безопасности

> **Статус:** Актуальная

Этот каталог содержит документацию по системе аутентификации, авторизации и безопасности проекта.

   - **Статус:** ✅ Актуальна

3. **[TELEGRAM_OAUTH_SETUP.md](./TELEGRAM_OAUTH_SETUP.md)**
   - **Часть системы:** Интеграция с Telegram OAuth

   - **Статус:** ✅ Актуальна

4. **[SECURITY_FIXES.md](./SECURITY_FIXES.md)**
   - **Часть системы:** Исправления безопасности
   - **Содержание:** Список исправленных уязвимостей и проблем безопасности
   - **Статус:** ✅ Актуальна (отчет о исправлениях)

5. **[FRONTEND_SECURITY_REVIEW.md](./FRONTEND_SECURITY_REVIEW.md)**

   - **Статус:** ✅ Актуальна

## Логика именования файлов

Все файлы документации по аутентификации именуются по следующей логике:

```
<TЕМА>_<ТИП>.md
```

**Где:**
- `<ТЕМА>` — тема документа (AUTHENTICATION, USER_AUTHENTICATION, TELEGRAM_OAUTH, SECURITY, FRONTEND_SECURITY)
- `<ТИП>` — тип документа (SETUP, FIXES, REVIEW)

## Связанные файлы

### Код

**Backend:**
- `apps/api/src/auth/` — модуль аутентификации
- `apps/api/src/auth/auth.service.ts` — сервис аутентификации
- `apps/api/src/auth/guards/` — guards для защиты endpoints

**Frontend:**
- `apps/web/src/hooks/useAuth.ts` — React хук для аутентификации
- `apps/web/src/lib/api.ts` — функции для работы с API (включая аутентификацию)

## Обновление документации

При внесении изменений в систему аутентификации обновляйте соответствующую документацию:

- **Изменения в процессе аутентификации** → обновить `AUTHENTICATION.md`
- **Новые методы аутентификации** → добавить в соответствующий документ
- **Исправления безопасности** → обновить `SECURITY_FIXES.md`
