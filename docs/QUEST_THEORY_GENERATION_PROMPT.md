# Промпт для генерации теории и примеров квестов

> **ВАЖНО:** 
> - **Контентная база:** `QUESTS_STRUCTURED_CONTENT.md` и `QUESTS_THEORIES_MAPPING.md` являются источниками истины для всех данных квестов
> - **Методология:** Этот документ подчинен структуре из `QUEST_CONTENT_STRUCTURE.md` и примерам из `QUEST_THEORY_EXAMPLES.md`
> - **Источник теорий:** Все теоретические блоки находятся в `QUESTS_THEORIES_MAPPING.md`

## Назначение

Этот промпт используется для генерации раздела "Подробнее" (теория и примеры) для квестов в игре "Архитектор лидерства". 
Раздел помогает пользователю понять не только **что** делать, но и **как** это делать в реальности, и **почему** это важно для развития лидерства.

**Структура теории** определяется в `QUEST_CONTENT_STRUCTURE.md`:
- Теоретическое объяснение концепции
- Что это значит на практике
- Конкретные примеры применения
- Практические советы
- Как интегрировать в ежедневную практику

**Примеры готовых теорий:**
- `QUEST_THEORY_EXAMPLES.md` — методологические примеры структуры
- `QUESTS_THEORIES_MAPPING.md` — полный маппинг всех теорий (контентная база)

## Контекст

Игра "Архитектор лидерства" — это система развития лидерских способностей через практику в реальных ситуациях. 
Квесты создаются на основе анализа ситуаций пользователя и направлены на развитие конкретных способностей из дерева способностей.

## Промпт

```
Ты — эксперт по лидерству и развитию способностей. Твоя задача — создать подробное описание теории и примеров для квеста, 
который поможет пользователю развить конкретную способность через практику.

КОНТЕКСТ КВЕСТА:
- Название: {quest_title}
- Описание: {quest_description}
- Тип: {quest_type} (micro/weekly/story/in-person)
- Связанные способности: {linked_nodes}
- Шаги выполнения: {quest_steps}
- Критерии успеха: {quest_criteria}

КОНТЕКСТ СПОСОБНОСТИ:
{ability_description} — описание способности из дерева способностей
{ability_practical_meaning} — что это значит на практике
{ability_examples} — примеры применения способности

ЗАДАЧА:
Создай раздел "Подробнее" (теория и примеры) для этого квеста. Раздел должен включать:

1. **Теоретическое объяснение способности**
   - Что это за способность и почему она важна для лидерства
   - Как она связана с другими способностями
   - Какое место занимает в развитии лидера

2. **Что это значит на практике**
   - Конкретное объяснение, как эта способность проявляется в реальных ситуациях
   - Что нужно делать, а чего избегать
   - Какие ошибки часто делают при развитии этой способности

3. **Конкретные примеры применения**
   - 2-3 реальных примера ситуаций, где можно применить эту способность
   - Примеры того, как это выглядит "хорошо" и "плохо"
   - Примеры из разных контекстов (работа, команда, личное развитие)

4. **Практические советы**
   - Как начать практиковать эту способность
   - С чего начать, если это новая способность
   - Как заметить прогресс
   - Что делать, если не получается

5. **Как интегрировать в ежедневную практику**
   - Как сделать эту способность частью своей практики
   - Когда и где можно практиковать
   - Как отслеживать применение

СТИЛЬ:
- Пиши на русском языке
- Используй простой, понятный язык
- Будь конкретным, избегай абстракций
- Используй примеры из реальной жизни
- Будь поддерживающим и мотивирующим
- Структурируй текст с помощью заголовков и списков

ФОРМАТ ВЫВОДА:
Верни текст в формате Markdown, готовый для отображения на странице квеста. 
Текст должен быть структурированным и легко читаемым.

ВАЖНО:
- Фокус на практическом применении, а не на теории
- Примеры должны быть релевантными для реальных ситуаций лидерства
- Текст должен мотивировать к действию
- Учитывай тип квеста (micro квесты требуют более конкретных примеров, story квесты — более глубокого объяснения)

КРИТИЧЕСКИ ВАЖНО (согласно QUEST_CONTENT_STRUCTURE.md):
❌ НЕ ДУБЛИРУЙ:
- Информацию из шагов выполнения (quest_steps) — она уже в отдельной секции
- Критерии успеха (quest_criteria) — они уже в отдельной секции
- Краткое описание цели (quest_description) — оно уже в описании

✅ ФОКУС НА:
- Объяснении "ПОЧЕМУ" и "КАК", а не на "ЧТО делать" (это в шагах)
- Связи с методологией архитектурного лидерства
- Пояснении терминов и концепций
- Обосновании важности способности
- Конкретных примерах из практики
```

## Использование

Этот промпт используется в следующих случаях:

1. **При создании квеста из анализа ситуации** — когда система анализирует ситуацию пользователя и создает квест, 
   для него автоматически генерируется раздел "Подробнее" с теорией и примерами.

2. **При обновлении существующих квестов** — если квест не имеет раздела "Подробнее", 
   его можно сгенерировать с помощью этого промпта.

3. **При создании шаблонных квестов** — для предопределенных квестов из каталога.

## Интеграция с LLM

Промпт используется с LLM сервисом (например, OpenAI GPT-4) для генерации контента. 
Результат сохраняется в поле `criteria.theory_and_examples` квеста согласно структуре из `QUEST_CONTENT_STRUCTURE.md`.

## Пример использования

```typescript
async function generateQuestTheory(quest: Quest, abilityNode: AbilityNode): Promise<string> {
  const prompt = `
Ты — эксперт по лидерству и развитию способностей. Твоя задача — создать подробное описание теории и примеров для квеста.

КОНТЕКСТ КВЕСТА:
- Название: ${quest.title}
- Описание: ${quest.description}
- Тип: ${quest.type}
- Связанные способности: ${quest.linked_nodes.join(', ')}
- Шаги выполнения: ${quest.steps.map(s => s.description).join('\n')}
- Критерии успеха: ${quest.criteria.description}

КОНТЕКСТ СПОСОБНОСТИ:
${abilityNode.full_description}
${abilityNode.practical_meaning}
Примеры: ${abilityNode.examples.join(', ')}

ЗАДАЧА:
Создай раздел "Подробнее" (теория и примеры) для этого квеста...
  `;

  const response = await llmService.generate(prompt);
  return response.text;
}
```

## Качество генерации

Для обеспечения качества генерации:

1. **Проверка релевантности** — сгенерированный текст должен быть релевантен квесту и способности
2. **Проверка структуры** — текст должен содержать все необходимые разделы
3. **Проверка примеров** — примеры должны быть конкретными и применимыми
4. **Редактирование** — при необходимости текст можно отредактировать вручную

## Обновление промпта

Промпт может быть обновлен на основе:
- Обратной связи пользователей
- Анализа качества сгенерированного контента
- Изменений в структуре квестов или способностей
- Новых требований к контенту
