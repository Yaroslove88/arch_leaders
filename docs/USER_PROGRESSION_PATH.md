## Введение в систему развития {#введение}

Leadership Architect — это система развития лидерских способностей через практику. Вместо традиционных курсов здесь используется геймифицированный подход с деревом способностей, квестами и опытом (XP).

### Основные компоненты системы:

1. **Дерево способностей** — 6 веток развития с 37 узлами
2. **Квесты** — практические задания разных типов и сложности
3. **Опыт (XP)** — валюта прогрессии, получаемая за выполнение квестов
4. **Состояния узлов** — уровни освоения каждой способности
5. **Ветки развития** — направления, по которым можно развиваться

## Первые шаги: регистрация и знакомство {#первые-шаги}

### Шаг 1: Регистрация

Когда пользователь впервые заходит в систему:

1. **Авторизация через Telegram OAuth или Email**
   - Создается профиль пользователя
   - Инициализируется пустое дерево способностей

2. **Начальное состояние дерева:**
   - Все узлы находятся в состоянии `locked` (заблокированы)
   - XP на всех узлах: 0
   - Открывается только стартовый узел "Точка опоры" в ветке "Субъектность"

3. **Первый доступный узел:**
   - **node_grounding_point** (Точка опоры)
   - Ветка: Субъектность
   - Уровень: basic
   - Состояние: `available` (доступен сразу после регистрации)
   - XP требуется: 0 (базовый узел)
   - Разблокировка: доступен по умолчанию

### Шаг 2: Знакомство с интерфейсом

Пользователь видит:
- **Дерево способностей** — визуализация всех веток и узлов
- **Доступные квесты** — список заданий, которые можно выполнить
- **Прогресс** — текущий XP и состояние узлов

### Шаг 3: Первый квест

После регистрации пользователь сразу может начать:
- Выбрать первый квест из категории "reflection" (рефлексия)
- Этот квест связан с узлом "Точка опоры"

## Механика получения опыта (XP) {#механика-опыта}

### Источники XP

Опыт можно получить только одним способом: **выполнение квестов**.

### Типы квестов и базовое XP

| Тип квеста | Base XP | Reflection XP | Максимум | Описание |
|-----------|---------|---------------|----------|----------|
| **micro** | 20 | 80 | 100 | Короткие задания, 5-15 минут |
| **weekly** | 40 | 160 | 200 | Недельные задания, требуют регулярной практики |
| **story** | 60 | 240 | 300 | История-кейс, требует анализа и применения |
| **in-person** | 100 | 400 | 500 | Очные сессии (коучинг, менторинг, групповые) |

**Ключевое изменение:** Reflection XP — основной источник XP (80% от максимума). Без рефлексии → только Base XP.

**Правило:** Если рефлексия отсутствует или меньше 300 символов → начисляется только Base XP.

### Как XP применяется к узлам

1. **Пользователь выбирает квест**
   - Квест может быть привязан к одному или нескольким узлам
   - При выборе указывается, к какому узлу применить XP

2. **Выполнение квеста**
   - Пользователь проходит все шаги квеста
   - Записывает результаты, рефлексию, ответы

3. **Завершение квеста**
   - После завершения система рассчитывает итоговый XP
   - XP применяется к выбранному узлу

### Расчёт итогового XP

**Новая упрощенная формула:**
```
Итоговый XP = (Base XP + Reflection XP) × Node Level Multiplier × State Multiplier
```

**Проверка рефлексии:**
- Если рефлексия есть (Evidence с типом 'reflection', длина >= 300 символов) → Reflection XP = полный
- Если рефлексии нет или слишком короткая → Reflection XP = 0

#### Множитель 1: Node Level Multiplier (уровень узла)

| Уровень узла | Множитель | Описание |
|-------------|-----------|----------|
| **basic** | 1.0x | Базовые узлы, учатся быстрее |
| **mid** (intermediate) | 0.8x | Средний уровень сложности |
| **advanced** | 0.6x | Продвинутый уровень |
| **master** | 0.4x | Мастерский уровень, требует больше практики |

**Пример:**
- Квест дает 100 XP (20 base + 80 reflection)
- Применяется к узлу уровня "advanced"
- Множитель: 0.6x
- Итого: 100 × 0.6 = **60 XP**

#### Множитель 2: State Multiplier (состояние узла)

| Состояние узла | Множитель | Примечание |
|---------------|-----------|------------|
| **locked** | 0.0x | XP копится, но не применяется до разблокировки |
| **available** | 0.7x | Узел доступен, но еще не активен (новое значение) |
| **active** | 1.0x | Узел активен, пользователь фокусируется на нем |
| **unlocked** | 0.8x | Узел разблокирован, продолжение развития (новое значение) |
| **integrated** | 0.6x | Узел интегрирован, углубленное развитие (новое значение) |

**Важно:** Если узел в состоянии `locked`, XP копится, но не применяется. При разблокировке XP может быть применен.

**Убрано:**
- ❌ Prerequisite Multiplier (больше не используется)
- ❌ Diminishing Returns (убрано для упрощения)

### Пример полного расчёта XP (новая система)

**Условия:**
- Тип квеста: **weekly** (40 Base XP + 160 Reflection XP)
- Рефлексия: есть (Evidence с типом 'reflection', длина >= 300 символов)
- Узел: **node_self_regulation** (Саморегуляция)
  - Уровень: **basic** (1.0x)
  - Состояние: **available** (0.7x)
  - Текущий прогресс: 30 XP из 100 (30%)

**Расчёт:**
1. Base XP: 40
2. Reflection XP: 160 (рефлексия есть)
3. Total XP: 40 + 160 = 200 XP
4. Node Level Multiplier: 1.0x (basic)
5. State Multiplier: 0.7x (available)

**Итоговый XP = (40 + 160) × 1.0 × 0.7 = 200 × 0.7 = 140 XP**

**Результат:**
- До: 30 XP / 100 XP (30%)
- После: 30 + 140 = 170 XP / 100 XP (170%)
- Узел переходит в состояние **unlocked** (100%+ достигнуто)

### Пример без рефлексии

**Условия:**
- Тип квеста: **weekly** (40 Base XP + 160 Reflection XP)
- Рефлексия: отсутствует или слишком короткая (< 300 символов)
- Узел: **node_self_regulation** (Саморегуляция)
  - Уровень: **basic** (1.0x)
  - Состояние: **available** (0.7x)

**Расчёт:**
1. Base XP: 40
2. Reflection XP: 0 (рефлексии нет)
3. Total XP: 40 + 0 = 40 XP
4. Node Level Multiplier: 1.0x (basic)
5. State Multiplier: 0.7x (available)

**Итоговый XP = (40 + 0) × 1.0 × 0.7 = 40 × 0.7 = 28 XP**

**Результат:**
- Начисляется только 28 XP (вместо 140 XP с рефлексией)
- **Важно:** Рефлексия дает 80% от максимального XP!

## Система веток и узлов {#система-веток-и-узлов}

### 6 веток развития

Система включает 6 основных направлений развития:

#### 1. Субъектность (branch_subjectivity)
**Описание:** Внутренняя устойчивость и способность удерживать позицию. Действие из себя, а не из инструкции.

**Узлы в ветке:**
- **Точка опоры** (basic, 0 XP) — доступен сразу
- **Саморегуляция** (basic, 100 XP)
- **Различение ролей** (intermediate, 200 XP)
- **Разбор сценария** (intermediate, 200 XP)
- **Субъект в системе** (advanced, 500 XP)
- **Авторство решений** (advanced, 500 XP)
- **Освобождение лидера** (master, 1000 XP)

**Ключевые способности:**
- Внутренняя устойчивость
- Управление состоянием (тело, эмоции, мысли)
- Осознание внутренних ролей
- Действие из субъектности, а не из реакции

#### 2. Архитектурное мышление (branch_architectural_thinking)
**Описание:** Мышление формами, а не задачами. Создание форм, которые делают взаимодействия эффективными.

**Узлы в ветке:**
- **Архитектура сцепки** (basic, 100 XP)
- **Поле различий** (basic, 100 XP)
- **Системное мышление** (intermediate, 200 XP)
- **Сценарное мышление** (intermediate, 200 XP)
- **Сборка форм** (advanced, 500 XP)
- **Контейнирование** (advanced, 500 XP)
- **Мышление через форму** (master, 1000 XP)

**Ключевые способности:**
- Создание связей между людьми и командами
- Системное видение
- Работа с неопределенностью через сценарии
- Проектирование структур, которые работают сами

#### 3. Устойчивость (branch_resilience)
**Описание:** Меняться, не теряя целостности. Способность выдерживать давление и восстанавливаться.

**Узлы в ветке:**
- **Личная устойчивость** (basic, 100 XP)
- **Диагностика слабых зон** (basic, 100 XP)
- **Навыки восстановления** (intermediate, 200 XP)
- **Работа с эмоциями** (intermediate, 200 XP)
- **Когнитивная зрелость** (advanced, 500 XP)
- **Энергия роли** (advanced, 500 XP)
- **Личная устойчивость (мастер)** (master, 1000 XP)

**Ключевые способности:**
- Выдерживание давления
- Диагностика утечек энергии
- Практики восстановления
- Управление эмоциональным состоянием

#### 4. Ответственность (branch_responsibility)
**Описание:** Ответственность как связь, а не груз. Принятие ответственности за результаты и процессы.

**Узлы в ветке:**
- **Ответственность как форма** (basic, 100 XP)
- **Диагностика провисания ответственности** (basic, 100 XP)
- **Делегирование как сцепка** (intermediate, 200 XP)
- **Работа с верхним полем** (intermediate, 200 XP)
- **Освобождение лидера** (advanced, 500 XP)
- **Shared Leadership** (advanced, 500 XP)
- **Психологическая собственность** (master, 1000 XP)

**Ключевые способности:**
- Понимание ответственности как связи
- Диагностика провалов в ответственности
- Делегирование через создание связи
- Создание психологической собственности у команды

#### 5. Обратная связь (branch_feedback)
**Описание:** Обратная связь как развитие, а не контроль. Способность давать и принимать обратную связь.

**Узлы в ветке:**
- **Типы обратной связи** (basic, 100 XP)
- **Язык различий** (basic, 100 XP)
- **Приём обратной связи через уязвимость** (intermediate, 200 XP)
- **Feedforward** (intermediate, 200 XP)
- **REDE Model** (advanced, 500 XP)
- **Window Gazer vs Mirror Holder** (advanced, 500 XP)
- **Развитие обратной связи (мастер)** (master, 1000 XP)

**Ключевые способности:**
- Различение типов обратной связи
- Дача обратной связи через язык различий
- Приём обратной связи через уязвимость
- Применение моделей обратной связи

#### 6. Среда зрелости (branch_maturity_environment)
**Описание:** Создание среды, где люди растут. Создание условий для развития команды и организации.

**Узлы в ветке:**
- **Среда зрелости** (basic, 100 XP)
- **Передача субъектности** (basic, 100 XP)
- **Удержание сцены** (intermediate, 200 XP)
- **Институционализация** (intermediate, 200 XP)
- **Vertical Development** (advanced, 500 XP)
- **DDO (Deliberately Developmental Organization)** (advanced, 500 XP)
- **Зрелое расставание** (master, 1000 XP)

**Ключевые способности:**
- Создание базовых условий для развития
- Поддержка автономии других
- Создание форм для субъектности
- Вертикальное развитие команды

### Уровни узлов (Tiers)

Каждый узел имеет уровень сложности, который влияет на количество требуемого XP:

| Уровень | XP требуется | Время освоения* | Описание |
|---------|-------------|-----------------|----------|
| **basic** | 0-100 | 2-3 месяца | Базовые способности, доступны в начале |
| **intermediate** (mid) | 200 | 5-6 месяцев | Средний уровень, требуют базовых навыков |
| **advanced** | 500 | 12-15 месяцев | Продвинутый уровень, требует практики |
| **master** | 1000 | 24-30 месяцев | Мастерский уровень, требует глубокой интеграции |

*Время указано при регулярной практике (2-3 квеста в неделю)

### Пререквизиты узлов

Многие узлы имеют **пререквизиты** — другие узлы, которые должны быть разблокированы сначала.

**Пример:**
- Узел "Авторство решений" (advanced)
  - Пререквизиты:
    1. "Точка опоры" (должен быть unlocked)
    2. "Саморегуляция" (должен быть unlocked)
    3. "Различение ролей" (должен быть unlocked)

Если пререквизиты не выполнены:
- Узел остается в состоянии `locked`
- XP применяется с множителем 0.1x-0.5x (в зависимости от количества недостающих пререквизитов)
- XP сохраняется и применяется при разблокировке

## Типы квестов и заданий {#типы-квестов}

### Классификация квестов

Квесты различаются по:
1. **Типу** (micro, weekly, story, in-person)
2. **Связи с узлами** (каким способностям развивает)
3. **Типу развития** (reflection, practice, theory, mixed)

### Micro квесты (100 XP базовый, 50 Skill XP)

**Характеристики:**
- Время выполнения: 5-15 минут
- Частота: можно выполнять несколько в день
- Цель: быстрая практика конкретного навыка

**Примеры:**
- "Контейнирование напряжения" — 10-минутная практика удержания паузы
- "Различение фактов и интерпретаций" — анализ ситуации за 15 минут
- "Наблюдение за стрессом" — практика самонаблюдения

**Когда использовать:**
- Для регулярной практики
- Для быстрого прогресса в начале узла
- Для закрепления навыка после более глубокого изучения

### Weekly квесты (200 XP базовый, 100 Skill XP)

**Характеристики:**
- Время выполнения: неделя
- Частота: 1-2 в неделю
- Цель: системная практика через неделю

**Примеры:**
- "Неделя саморегуляции" — ежедневная практика управления состоянием
- "Неделя обратной связи" — дача и получение обратной связи в течение недели
- "Неделя устойчивости" — практика восстановления после нагрузок

**Когда использовать:**
- Для глубокого погружения в навык
- Для интеграции навыка в повседневную практику
- Для системного развития способности

### Story квесты (300 XP базовый, 150 Skill XP)

**Характеристики:**
- Время выполнения: 2-4 часа (может быть распределено на несколько дней)
- Частота: 1-2 в месяц
- Цель: глубокий анализ и применение через кейс

**Примеры:**
- "Архитектурное мышление" — разбор реальной ситуации через системное мышление
- "Развитие команды" — проработка стратегии развития команды
- "Путь к зрелости" — анализ перехода от управления к архитектуре

**Когда использовать:**
- Для комплексной проработки навыка
- Для применения нескольких навыков одновременно
- Для глубокого понимания концепций

### In-person квесты (500 XP базовый, 250 Skill XP)

**Характеристики:**
- Время выполнения: 1-2 часа (очная сессия)
- Частота: 1-2 в месяц
- Цель: работа с коучем, ментором или группой

**Типы in-person квестов:**
1. **Коучинговая сессия** — работа с коучем над конкретной способностью
2. **Групповая рефлексия** — обмен опытом в группе
3. **Менторская сессия** — стратегические вопросы с опытным лидером

**Примеры:**
- "Коучинговая сессия по обратной связи" — работа с коучем над практикой обратной связи
- "Групповая практика устойчивости" — совместная практика техник восстановления
- "Менторская сессия" — обсуждение стратегических вопросов лидерства

**Когда использовать:**
- Для сложных вопросов, требующих экспертной поддержки
- Для глубокой проработки препятствий
- Для ускорения развития через обратную связь

### Связь квестов с узлами

Каждый квест может быть привязан к одному или нескольким узлам:

**Односторонняя связь:**
- Квест "Контейнирование напряжения" → узел "Контейнирование"

**Множественная связь:**
- Квест "Неделя устойчивости" → узлы:
  - "Личная устойчивость"
  - "Диагностика слабых зон"
  - "Навыки восстановления"

**При выборе квеста:**
- Пользователь видит, какие узлы получат XP
- Можно выбрать приоритетный узел для применения XP
- Можно распределить XP между несколькими узлами (если квест поддерживает)

## Прогрессия по состояниям узлов {#прогрессия-по-состояниям}

### 5 состояний узлов

Узел проходит через следующие состояния по мере развития:

```
locked → available → active → unlocked → integrated
         (0.1%+)     (30%+)    (100%+)   (150%+)
                   + relevance 30%+
```

### Состояние 1: Locked (заблокирован)

**Условия:**
- Узел еще не разблокирован
- Пререквизиты не выполнены (если есть)
- Или начальный узел еще не активирован

**Что можно делать:**
- ✅ Видеть описание узла
- ✅ Видеть, какие пререквизиты нужны
- ❌ Нельзя получать XP (XP сохраняется в резерве)
- ❌ Нельзя выбрать узел как активный

**Множитель XP:** 0.0x (но XP сохраняется и применяется при разблокировке)

**Как разблокировать:**
- Выполнить все пререквизиты (разблокировать связанные узлы)
- Или выполнить условия разблокировки (например, выполнить 3 квеста определенного типа)

### Состояние 2: Available (доступен)

**Условия:**
- Пререквизиты выполнены
- Узел разблокирован
- Прогресс: 0.1%+ (получен хотя бы 1 XP)

**Что можно делать:**
- ✅ Получать XP (с множителем 0.5x)
- ✅ Видеть прогресс
- ✅ Выбирать квесты, связанные с узлом
- ❌ Еще нельзя выбрать как активный (нужно 30%+ прогресса)

**Множитель XP:** 0.5x

**Пример:**
- Узел требует 100 XP
- Получено: 5 XP (5%)
- Состояние: `available`

### Состояние 3: Active (активен)

**Условия:**
- Прогресс: 30%+ от xp_required
- Relevance: 30%+ (узел релевантен текущей практике)

**Что можно делать:**
- ✅ Получать XP с полным множителем (1.0x)
- ✅ Фокусироваться на развитии этого узла
- ✅ Видеть детальные подсказки и практики
- ✅ Отмечать progress milestones

**Множитель XP:** 1.0x

**Как перейти в active:**
1. Набрать 30%+ прогресса через квесты
2. Узел автоматически становится доступным для активации
3. Пользователь может выбрать узел как "активный" в интерфейсе

**Пример:**
- Узел требует 100 XP
- Получено: 35 XP (35%)
- Relevance: 40% (пользователь часто выполняет квесты по этой теме)
- Состояние: `active` (можно выбрать)

### Состояние 4: Unlocked (разблокирован)

**Условия:**
- Прогресс: 100%+ от xp_required
- Узел полностью освоен на базовом уровне

**Что можно делать:**
- ✅ Использовать способность в практике
- ✅ Разблокировать зависимые узлы (если есть)
- ✅ Продолжать развитие до integrated
- ✅ Видеть новые возможности и применения

**Множитель XP:** 1.0x (можно продолжать развивать)

**Переход в unlocked:**
- Автоматически при достижении 100% прогресса
- Система отправляет уведомление
- Разблокируются зависимые узлы (если пререквизиты выполнены)

**Пример:**
- Узел требует 100 XP
- Получено: 110 XP (110%)
- Состояние: `unlocked`
- Зависимые узлы становятся `available` (если их пререквизиты выполнены)

### Состояние 5: Integrated (интегрирован)

**Условия:**
- Прогресс: 150%+ от xp_required
- Способность глубоко интегрирована в практику

**Что можно делать:**
- ✅ Способность применяется естественно, без усилий
- ✅ Можно обучать других этой способности
- ✅ Видеть новые возможности применения
- ✅ Продолжать развитие до мастерского уровня (200%+)

**Множитель XP:** 1.0x (но с diminishing returns после 120%)

**Переход в integrated:**
- Автоматически при достижении 150% прогресса
- Система отмечает это как значимое достижение
- Открываются возможности для менторства и обучения других

**Пример:**
- Узел требует 100 XP
- Получено: 160 XP (160%)
- Состояние: `integrated`
- Пользователь может стать ментором по этой способности

## Рекомендации по эффективному развитию

### 1. Начните с одной ветки

**Почему:**
- Быстрее увидите прогресс
- Узлы одной ветки поддерживают друг друга
- Легче понять систему

**Как:**
- Выберите ветку, которая наиболее релевантна сейчас
- Разблокируйте 2-3 базовых узла
- Затем переходите к другой ветке

### 2. Регулярность важнее интенсивности

**Рекомендация:**
- 2-3 квеста в неделю лучше, чем 10 квестов за один день
- Регулярная практика интегрирует навыки лучше
- Weekly квесты рассчитаны на неделю практики

**Оптимальный ритм:**
- Micro квесты: 1-2 в день (быстрая практика)
- Weekly квесты: 1-2 в неделю (глубокая практика)
- Story квесты: 1-2 в месяц (комплексная проработка)
- In-person квесты: 1 в месяц (экспертная поддержка)

### 3. Фокусируйтесь на active узлах

**Почему:**
- Active узлы получают полный множитель XP (1.0x)
- Фокус ускоряет развитие
- Можно видеть прогресс быстрее

**Как:**
- Выберите 1-2 узла как активные
- Выполняйте квесты, связанные с активными узлами
- Переключайтесь на новые узлы после разблокировки

### 4. Используйте синергию между ветками

**Примеры:**
- "Саморегуляция" (Субъектность) + "Личная устойчивость" (Устойчивость)
- "Системное мышление" (Архитектурное) + "Субъект в системе" (Субъектность)
- "Обратная связь" + "Передача субъектности" (Среда зрелости)

**Как:**
- Выбирайте квесты, которые развивают несколько узлов
- Обращайте внимание на связи между ветками
- Используйте навыки из одной ветки для развития другой

### 5. Не игнорируйте пререквизиты

**Почему:**
- Без пререквизитов XP применяется с множителем 0.1x-0.5x
- Пререквизиты создают основу для продвинутых навыков
- Попытка прыгнуть вперед замедляет развитие

**Как:**
- Всегда проверяйте пререквизиты перед выбором узла
- Разблокируйте базовые узлы перед продвинутыми
- Используйте визуализацию дерева для планирования

### 6. Используйте разные типы квестов

**Стратегия:**
- **Micro** — для регулярной практики и быстрого прогресса
- **Weekly** — для глубокой интеграции навыка
- **Story** — для комплексного применения
- **In-person** — для преодоления препятствий и ускорения

**Пример недели:**
- Понедельник: micro квест (быстрый старт недели)
- Вторник-Четверг: weekly квест (глубокая практика)
- Пятница: micro квест (закрепление)
- Суббота: story квест (комплексная проработка)

### 7. Отслеживайте прогресс

**Метрики для отслеживания:**
- Количество разблокированных узлов
- Прогресс по веткам (% завершенности)
- Количество integrated узлов
- Регулярность выполнения квестов

**Как:**
- Регулярно просматривайте дерево способностей
- Отмечайте milestones (unlocked, integrated)
- Используйте статистику для мотивации

## Часто задаваемые вопросы

### Q: Сколько времени нужно, чтобы разблокировать все узлы?

**A:** При регулярной практике (2-3 квеста в неделю):
- **Базовые узлы** (100 XP): 2-3 месяца
- **Intermediate узлы** (200 XP): 5-6 месяцев
- **Advanced узлы** (500 XP): 12-15 месяцев
- **Master узлы** (1000 XP): 24-30 месяцев

**Полное дерево (37 узлов):** ~2-3 года активной практики

### Q: Можно ли развивать несколько веток одновременно?

**A:** Да, это даже рекомендуется! Но:
- Начните с 1-2 веток для понимания системы
- Затем добавляйте новые ветки постепенно
- Обращайте внимание на синергию между ветками

### Q: Что делать, если застрял на узле?

**A:** 
1. Проверьте пререквизиты — возможно, нужно разблокировать другие узлы
2. Используйте in-person квесты для получения поддержки
3. Попробуйте story квесты для комплексной проработки
4. Переключитесь на другую ветку, а потом вернитесь

### Q: Можно ли получить XP без выполнения квестов?

**A:** Нет, XP можно получить только за выполнение квестов. Это сделано для того, чтобы развитие происходило через практику, а не просто через чтение или просмотр.

### Q: Что происходит с XP, если узел locked?

**A:** XP сохраняется в "резерве" и автоматически применяется при разблокировке узла. Вы не теряете прогресс!

### Q: Как выбрать, какой узел развивать?

**A:** 
1. Выберите ветку, которая наиболее релевантна вашей текущей ситуации
2. Проверьте, какие узлы доступны (available)
3. Выберите узел, который решает вашу текущую проблему
4. Используйте активные узлы для фокуса

### Q: Можно ли "перескочить" через пререквизиты?

**A:** Технически можно получить XP, но:
- Множитель будет очень низким (0.1x-0.5x)
- Развитие будет медленнее, чем если выполнить пререквизиты
- Пререквизиты создают основу для продвинутых навыков
- Рекомендуется выполнять пререквизиты для эффективного развития

## Заключение

Leadership Architect — это система развития лидерских способностей через практику. Ключевые принципы:

1. **Практика важнее теории** — XP получается только за выполнение квестов
2. **Системность** — узлы связаны между собой через пререквизиты и ветки
3. **Индивидуальность** — каждый выбирает свой путь развития
4. **Регулярность** — постоянная практика важнее интенсивных рывков
5. **Глубина** — лучше развить несколько узлов глубоко, чем поверхностно все
