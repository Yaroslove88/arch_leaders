# Документация пользовательских потоков

> **Дата последнего обновления:** 15.01.2025  
> **Статус:** Актуальная

Этот каталог содержит документацию по пользовательским потокам (User Flow), онбордингу и анализу пользовательских данных.

---

## Структура документации

### 📋 Основные документы

1. **[USER_FLOW_DETAILED.md](./USER_FLOW_DETAILED.md)**
   - **Часть системы:** Детальные пользовательские потоки
   - **Содержание:** Детальные сценарии взаимодействия, первый запуск, создание записей, анализ, квесты, дерево способностей
   - **Статус:** ✅ Актуальна (полное описание потоков)

2. **[USER_SPECIFIC_DATA_ANALYSIS.md](./USER_SPECIFIC_DATA_ANALYSIS.md)**
   - **Часть системы:** Анализ пользовательских данных
   - **Содержание:** Методология анализа данных пользователя, персонализация, рекомендации
   - **Статус:** ✅ Актуальна

3. **[PRD_INTRODUCE_ONBOARDING.md](./PRD_INTRODUCE_ONBOARDING.md)**
   - **Часть системы:** PRD онбординга
   - **Содержание:** Product Requirements Document для системы онбординга пользователей
   - **Статус:** ✅ Актуальна (PRD)

---

## Логика именования файлов

Все файлы документации по пользовательским потокам именуются по следующей логике:

```
<ТЕМА>_<ТИП>.md
```

**Где:**
- `<ТЕМА>` — тема документа (USER_FLOW, USER_SPECIFIC_DATA, PRD_INTRODUCE)
- `<ТИП>` — тип документа (DETAILED, ANALYSIS, ONBOARDING)

---

## Связанные файлы

### Код

**Frontend:**
- `apps/web/src/app/introduce/page.tsx` — страница онбординга
- Все страницы приложения реализуют описанные пользовательские потоки

**Backend:**
- `apps/api/src/sessions/` — анализ ситуаций (часть потока)
- `apps/api/src/quests/` — генерация квестов (часть потока)

## Быстрый старт

1. **Для понимания пользовательских потоков:**
   - Начните с [USER_FLOW_DETAILED.md](./USER_FLOW_DETAILED.md)

2. **Для работы с онбордингом:**
   - Изучите [PRD_INTRODUCE_ONBOARDING.md](./PRD_INTRODUCE_ONBOARDING.md)

3. **Для анализа пользовательских данных:**
   - См. [USER_SPECIFIC_DATA_ANALYSIS.md](./USER_SPECIFIC_DATA_ANALYSIS.md)

---

## Обновление документации

При изменении пользовательских потоков:

- **Новые сценарии** → обновить `USER_FLOW_DETAILED.md`
- **Изменения в онбординге** → обновить `PRD_INTRODUCE_ONBOARDING.md`
- **Новые методы анализа** → обновить `USER_SPECIFIC_DATA_ANALYSIS.md`
