## Логика именования файлов

Все файлы документации по настройке именуются по следующей логике:

```
<ТЕМА>_<ТИП>.md
```

**Где:**
- `<ТЕМА>` — тема документа (SETUP, QUICK_START, WEB_START, DATABASE_SETUP, IMPLEMENTATION_PLAN, INTEGRATION)
- `<ТИП>` — тип документа (SUMMARY)

---

## Связанные файлы

### Код

**Конфигурация:**
- `package.json` — зависимости проекта
- `turbo.json` — конфигурация Turborepo
- `tsconfig.json` — конфигурация TypeScript
- `apps/api/prisma/schema.prisma` — схема базы данных

**Скрипты:**
- `scripts/` — скрипты для настройки и миграции

## Быстрый старт

1. **Для первого запуска:**
   - Начните с [QUICK_START.md](./QUICK_START.md)

2. **Для полной настройки:**
   - Используйте [SETUP.md](./SETUP.md)

3. **Для настройки БД:**
   - См. [DATABASE_SETUP.md](./DATABASE_SETUP.md)

4. **Для понимания архитектуры:**
   - Изучите [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md)
   - См. [INTEGRATION_SUMMARY.md](./INTEGRATION_SUMMARY.md)

---

## Обновление документации

При изменении процесса настройки:

- **Новые шаги установки** → обновить `SETUP.md`
- **Изменения в быстром старте** → обновить `QUICK_START.md`
- **Новые зависимости** → обновить соответствующие документы
