# Быстрый старт - Проверка отображения данных

## Шаг 1: Запуск API сервера

```bash
cd leadership-architect/apps/api
npm run start:dev
```

API должен запуститься на `http://localhost:3001`

**Проверка:** Откройте в браузере `http://localhost:3001/tree/semantic` - должно вернуться JSON с деревом (40 узлов)

## Шаг 2: Запуск веб-приложения

```bash
cd leadership-architect/apps/web
npm run dev
```

Веб должен запуститься на `http://localhost:3000`

## Шаг 3: Проверка отображения

### Дерево способностей (`/tree`)

1. Откройте `http://localhost:3000/tree`
2. Должно отобразиться:
   - 6 веток (Субъектность, Архитектурное мышление, Устойчивость, Ответственность, Обратная связь, Среда зрелости)
   - 40 узлов (всего)
   - При клике на узел - модальное окно с описанием

**Если не видно узлов:**
- Откройте консоль браузера (F12) - проверьте ошибки
- Проверьте, что API отвечает: `http://localhost:3001/tree/semantic`
- Проверьте логи API сервера

### Кейсы (`/cases`)

1. Откройте `http://localhost:3000/cases`
2. Должно отобразиться 6 интерактивных кейсов
3. При клике на кейс - переход на страницу прохождения

**Если не видно кейсов:**
- Проверьте `http://localhost:3001/cases` - должен вернуть JSON с кейсами
- Проверьте файл `data/interactive-cases.json` - должен существовать

### Квесты (`/quests`)

1. Откройте `http://localhost:3000/quests`
2. Должны отобразиться квесты (если есть в базе данных)

**Если нет квестов:**
- Это нормально, если база данных пустая
- Создайте ситуацию через `/entries/new` для генерации квестов

## Диагностика проблем

### В консоли браузера (F12) должны быть логи:

```
Tree loaded: {tree_id: "tree_main", nodes: Array(40), ...}
Branches: 6, Nodes: 40, Filtered: 40
Cases loaded: 6
Quests loaded: X
```

### Если видите ошибки:

1. **"Failed to fetch"** - API сервер не запущен или недоступен
2. **"404 Not Found"** - Endpoint не зарегистрирован
3. **"Failed to load"** - Проблема с загрузкой файлов данных

### Проверка API endpoints:

Откройте в браузере и проверьте ответы:

- ✅ `http://localhost:3001/tree/semantic` - должен вернуть дерево
- ✅ `http://localhost:3001/cases` - должен вернуть `{"cases": [...]}`
- ✅ `http://localhost:3001/nodes/descriptions` - должен вернуть описания
- ✅ `http://localhost:3001/quests` - должен вернуть квесты

### Проверка файлов данных:

Убедитесь, что файлы существуют:

```bash
# Проверка seed файла
ls leadership-architect/packages/shared/src/seed/initial-ability-tree.json

# Проверка кейсов
ls leadership-architect/data/interactive-cases.json

# Проверка описаний
ls leadership-architect/data/node-descriptions.json
```

Все файлы должны существовать и быть валидным JSON.

## Ожидаемый результат

После правильной настройки вы должны видеть:

- **Дерево способностей:** 6 веток, 40 узлов
- **Кейсы:** 6 интерактивных кейсов
- **Квесты:** Зависит от данных в базе (может быть пусто)

Если что-то не работает, проверьте логи API сервера и консоль браузера для диагностики.
