# Дизайн карточки кейса

## Карточка кейса (до выбора ответа)

### HEADER

- **Навигация**: кнопка "← Назад" слева, индикатор сложности справа (⬤⬤○ Сложный)
- **Метка**: `portal.header_title` → "КЕЙС" (text-[10px], uppercase, ui-text-dim)
- **Заголовок**: `portal.case_name` → "Связь между командами" (text-xl, font-bold, ash-light)
- **Подзаголовок**: `portal.subtitle` → "Сопряжение ролей — Архитектурный взгляд" (text-sm, ui-text-dim)

### EVENT BLOCK

**Стиль**: obsidian-core, border-l-4 warm-amber

- **Метка события**: `event.label` → "СВЯЗЬ" (text-[10px], uppercase, warm-amber)
- **Описание**: `event.summary` → "Две команды реализуют один продукт разными подходами. Выявлена конфликтная точка взаимодействия." (text-base, ash-light)

### SPACE MAP (КОНТЕКСТ)

**Стиль**: graphite-structure, rounded-xl

**Таблица контекста** (text-xs, grid layout):

| Поле | Значение | JSON поле |
|------|----------|-----------|
| Компания | IT-компания, 2 продуктовые команды | `space_map.company` |
| Среда | Быстрый рост, расширение | `space_map.environment` |
| Ограничения | Не чётко описаны зоны ответственности | `space_map.constraints` |
| Участники | Тимлиды двух команд | `space_map.people` |
| Режим | Проблемная коммуникация | `space_map.mode` |

### BACKGROUND + FACTS (опционально)

- **Предыстория**: `background.story` → "В коллективе нет практики обсуждения сопряжения ролей и границ." (text-sm, ui-text-dim, italic)
- **Факты**: `facts.strict_facts` → "⚡ В предыдущем проекте подобный конфликт привёл к замедлению." (text-sm, tension-red/80, border-l-2 tension-red)

### DILEMMA

**Стиль**: text-center, py-6

- **Атмосфера**: `dilemma.ambiance` → "Малозаметный конфликт может стать фундаментальным." (text-sm, ui-text-dim, italic)
- **Вопрос**: `dilemma.question` → "Стоит ли настаивать на прямом диалоге — или передать регулирование на уровень архитекторов?" (text-lg, font-semibold, ash-light)

### POSITIONS

**Стиль**: space-y-3

Каждая позиция:
- **ID**: `positions[].id` → "А", "Б", "В" (крупно)
- **Описание**: `positions[].description` → текст позиции (font-medium, ash-light)
- **Тип**: `positions[].position_type` → тип позиции (text-xs, ui-text-dim)

**Стиль карточки позиции**: graphite-structure, border, rounded-xl, hover:border-catalyst-gold

**Примеры**:
- **А**: Инициировать личную встречу всех сторон (Прямое взаимодействие)
- **Б**: Передать урегулирование архитекторам (Делегирование наверх)
- **В**: Оставить решение на команды без кураторов (Полная автономия)

### EFFECTS + TAGS (footer)

- **Развивает**: `node_id` → `getNodeName()` → бейдж "Архитектурное мышление" (catalyst-gold badge)
- **Теги**: `symbols[]` + `strategic_tags[]` → ["Связь", "Архитектура"] (inner-violet/20, text-[10px])

## Карточка кейса (после выбора ответа)

### HEADER

Остаётся как было:
- ← Назад к кейсам
- ⬤○○ Базовый (обновлённая сложность)
- КЕЙС
- Связь между командами
- Сопряжение ролей — Архитектурный взгляд

### ВЫБРАННАЯ ПОЗИЦИЯ

**Стиль**: catalyst-gold border, bg-catalyst-gold/10

- **Метка**: "ВАШ ВЫБОР" (text-[10px], uppercase, catalyst-gold)
- **ID позиции**: `positions[selected].id` → "А" (text-2xl, font-bold, catalyst-gold)
- **Описание**: `positions[selected].description` → "Инициировать личную встречу всех сторон" (text-base, font-medium, ash-light)

### ПОСЛЕДСТВИЯ

**Стиль**: graphite-structure, rounded-xl

**Заголовок**: "ПОСЛЕДСТВИЯ ВЫБОРА" (text-[10px], uppercase, ui-text-dim)

Три блока последствий:

1. **СЕЙЧАС** (sage-green)
   - `positions[selected].consequence.immediate`
   - Пример: "Смягчение напряжённости, быстрое согласование."
   - Стиль: text-sm, ash-light

2. **ПОТОМ** (catalyst-gold)
   - `positions[selected].consequence.second_order`
   - Пример: "Нарастает доверие между командами."
   - Стиль: text-sm, ash-light

3. **СИСТЕМНО** (inner-violet)
   - `positions[selected].consequence.systemic`
   - Пример: "Укрепляются горизонтальные связи."
   - Стиль: text-sm, ash-light

### РЕФЛЕКСИЯ

**Стиль**: obsidian-core, border-l-4 warm-amber, rounded-xl

- **Метка**: "ПОДУМАЙТЕ" (text-[10px], uppercase, warm-amber)
- **Вопрос**: `positions[selected].reflection_prompt` → "Проще ли решать напрямую или отдать в структуру?" (text-base, ash-light, font-medium)

### ГЛУБЖЕ (опционально)

**Стиль**: опционально, если есть `reflection.questions`

- **Заголовок**: "ВОПРОСЫ ДЛЯ РАЗМЫШЛЕНИЯ" (text-[10px], uppercase, ui-text-dim)
- **Список**: `reflection.questions[]` → маркированный список (text-sm, ui-text-dim, space-y-2)
  - Когда команда учится — через контроль или открытый конфликт?
  - Что такое зрелая коммуникация между ролями?
  - Устойчивость связей появляется только через открытые 'стыки'.

### ДРУГИЕ ПОЗИЦИИ

**Стиль**: свёрнуто, можно развернуть

- **Триггер**: "▸ Посмотреть другие позиции" (text-sm, ui-text-dim, clickable)
- **При раскрытии**: показываются остальные позиции с кратким описанием последствий
  - Б — Передать урегулирование архитекторам → Появляется ощущение формализма...
  - В — Оставить решение на команды без кураторов → Временное усиление конфликтов...

### РЕЗУЛЬТАТ

**Стиль**: graphite-structure, sage-green border

- **Статус**: "● КЕЙС ЗАВЕРШЁН" (sage-green, font-medium)
- **Награда**: бейдж с XP (sage-green badge)
  - Пример: "Архитектурное мышление +5 XP"

### CTA

Две кнопки:

1. **Основная**: "К СЛЕДУЮЩЕМУ КЕЙСУ" (catalyst-gold bg, obsidian-core text)
2. **Вторичная**: "ВЕРНУТЬСЯ К СПИСКУ" (border, ui-text-dim)
