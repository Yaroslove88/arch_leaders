# Анализ применимости интерактивных кейсов к узлам способностей

## Критерии применимости кейсов

**Кейсы подходят для узлов, где:**
- Есть конкретная ситуация выбора/действия
- Есть несколько правдоподобных вариантов решения
- Можно смоделировать контекст (люди, среда, ограничения)
- Есть наблюдаемое поведение/решение

**Кейсы НЕ подходят для узлов, где:**
- Чисто внутренняя психологическая работа (рефлексия, саморегуляция)
- Концептуальное понимание без внешнего действия
- Долгосрочные процессы развития (cognitive maturity, vertical development)
- Метрики и измерения (collective efficacy)
