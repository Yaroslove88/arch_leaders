Актуальная документация находится в соответствующих тематических папках:

- **Правила проекта** → `.cursor/rules.md` (в корне проекта)
- **Статус проекта** → см. актуальные документы в `docs/`
- **Отчеты о выполнении** → см. соответствующие системы в `docs/`

---

## Использование архива

Документы в архиве сохранены для исторической справки и не должны использоваться как актуальные источники информации.

Если вам нужна информация из архивных документов:
1. Проверьте, есть ли актуальная версия в соответствующих папках `docs/`
2. Если актуальной версии нет, используйте архивный документ с осторожностью
3. При необходимости обновите актуальную документацию на основе архивной
