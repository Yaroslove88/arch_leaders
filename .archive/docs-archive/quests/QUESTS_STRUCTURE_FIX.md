# Исправление структуры квестов

## Проблема

В файле `quest-templates.json` была нарушена архитектура данных:
- Всё содержимое (описание, шаги, критерии, награда, теория) было свалено в поле `description`
- Шаги (`steps`) содержали мусорные данные (одиночные буквы)
- Критерии (`criteria.description`) содержали мусорные данные
- Теория и примеры не были отделены от основного описания
- При отображении на UI всё дублировалось несколько раз

## Решение

Создан скрипт `scripts/restructure-quest-templates.py`, который:
1. Парсит `description` и извлекает структурированные данные:
   - Краткое описание квеста
   - Шаги выполнения (с поддержкой форматов "Шаги:" и "Подготовка/Встреча/После встречи")
   - Критерии успеха
   - Теорию и примеры

2. Интегрирует теорию из `quest-theories-mapping.json` в `criteria.theory_and_examples`

3. Очищает мусорные данные из `steps` и `criteria`

4. Правильно структурирует награды и связанные узлы

## Новая структура квеста

```json
{
  "id": "quest_id",
  "title": "Название квеста",
  "description": "Краткое описание квеста (без шагов, критериев, теории)",
  "type": "micro|weekly|story|in-person",
  "steps": [
    {
      "order": 1,
      "title": "Подготовка" | null,
      "description": "Описание шага"
    }
  ],
  "criteria": {
    "type": "custom|evidence|count|streak",
    "items": ["Критерий 1", "Критерий 2"],
    "theory_and_examples": "Детальная теория и примеры..."
  },
  "reward": {
    "xp": 200,
    "skill_xp": 100
  },
  "linked_nodes": ["node_stress_tolerance", "node_recovery"]
}
```

## Отображение в UI

Компонент `apps/web/src/app/quests/[id]/page.tsx` правильно отображает:

1. **Описание** - только краткое описание из `description`
2. **Шаги выполнения** - структурированные шаги из `steps` (с группировкой по title, если есть)
3. **Критерии успеха** - список из `criteria.items` (если есть) или текст из `criteria.description`
4. **Теория и примеры** - из `criteria.theory_and_examples` (скрывается/показывается кнопкой)
5. **Награда** - из `reward`
6. **Связанные способности** - из `linked_nodes`

## Что нужно сделать

1. ✅ Файл `quest-templates.json` обновлен с правильной структурой
2. ⚠️ Существующие квесты в базе данных могут иметь старую структуру
   - Для обновления существующих квестов может потребоваться миграция
   - Новые квесты, созданные из шаблонов, будут иметь правильную структуру

## Пример правильной структуры

Для квеста "Групповая практика устойчивости":

- **description**: "Участвуйте в групповой сессии, где вы будете практиковать техники устойчивости и делиться опытом."
- **steps**: Структурированные шаги с разделами "Подготовка", "Встреча", "После встречи"
- **criteria.items**: ["Есть подготовка", "Участие в групповой сессии", ...]
- **criteria.theory_and_examples**: Полная теория с примерами и практикой

Вся информация отображается без дублирования.
