# Восстановление базовых квестов

## ✅ Что сделано

1. **Извлечены все квесты из GAME_CONTENT.md** - найдено **33 квеста**:
   - Micro: 19 квестов
   - Weekly: 5 квестов
   - Story: 4 квеста
   - In-person: 5 квестов
   - Все квесты имеют теории

2. **Созданы скрипты:**
   - `extract-quests-from-content.ts` - извлекает квесты из GAME_CONTENT.md
   - `create-base-quests-for-all-users.ts` - создает базовые квесты для всех пользователей

## 📋 Файлы

- **Шаблоны квестов:** `data/quest-templates.json` (33 квеста)
- **Теории квестов:** `data/quest-theories-mapping.json` (33 теории)

## 🚀 Использование

### Шаг 1: Извлечение квестов (уже выполнено)

```bash
cd leadership-architect
pnpm ts-node scripts/extract-quests-from-content.ts
```

Этот скрипт:
- Читает `docs/GAME_CONTENT.md`
- Извлекает все квесты
- Сохраняет в `data/quest-templates.json` и `data/quest-theories-mapping.json`

### Шаг 2: Создание базовых квестов для всех пользователей

```bash
cd leadership-architect/apps/api
pnpm tsx ../../scripts/create-base-quests-for-all-users.ts
```

**Важно:** Скрипт нужно запускать из директории `apps/api` с использованием `tsx`, так как там находится Prisma Client.

Этот скрипт:
- Находит всех активных пользователей
- Создает базовые квесты для каждого пользователя
- Добавляет теории к квестам
- Показывает статистику

## 📊 Результат

После выполнения скрипта:
- ✅ Все пользователи получат 33 базовых квеста
- ✅ Все квесты будут иметь теории в разделе "Подробнее"
- ✅ Квесты будут в статусе "backlog" (можно активировать)
- ✅ Квесты будут помечены как `source: 'base_template'`

## 🔍 Проверка

1. Откройте страницу квестов: `/quests`
2. Проверьте, что квесты отображаются
3. Откройте любой квест и проверьте раздел "Подробнее" с теорией

## 📝 Структура квеста

Каждый квест содержит:
- **Название** и **описание**
- **Шаги выполнения**
- **Критерии успеха**
- **Награда** (XP и skill XP)
- **Связанные узлы** дерева способностей
- **Теория и примеры** (в разделе "Подробнее")

## 🔄 Обновление квестов

Если нужно обновить квесты:
1. Обновите `docs/GAME_CONTENT.md`
2. Запустите `extract-quests-from-content.ts`
3. Запустите `create-base-quests-for-all-users.ts`

## ⚠️ Примечания

- Квесты создаются для всех активных пользователей
- Существующие квесты с таким же названием будут обновлены
- Теории добавляются автоматически на основе названия или связанных узлов
