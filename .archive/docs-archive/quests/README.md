## Актуальная документация

Актуальная документация по системе квестов находится в `docs/quests/`:

- **README.md** — индекс актуальной документации
- **QUEST_SYSTEM_COMPLETE.md** — полная системная спецификация
- **QUESTS_UX_UI_SPECIFICATION.md** — UX/UI спецификация
- **QUEST_CONTENT_STRUCTURE.md** — методология структуры контента
- **QUEST_THEORY_GENERATION_LOGIC.md** — логика генерации теорий
- **QUEST_THEORY_GENERATION_PROMPT.md** — промпты для генерации
- **QUEST_THEORY_EXAMPLES.md** — примеры теорий
- **UPDATE_QUEST_THEORIES.md** — инструкции по обновлению
- **QUEST_NODE_IDS_FIX.md** — техническая документация

## Использование архива

Документы в архиве сохранены для исторической справки и не должны использоваться как актуальные источники информации.

Если вам нужна информация из архивных документов:
1. Проверьте, есть ли актуальная версия в `docs/quests/`
2. Если актуальной версии нет, используйте архивный документ с осторожностью
3. При необходимости обновите актуальную документацию на основе архивной
